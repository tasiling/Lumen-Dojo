連接 Mac 與 LINE

Mac 轉錄

在安裝 BiliNote 的 Mac 登入這個測試站，下載配對檔。配對檔十分鐘內有效。

在 Mac 執行

下載到「下載項目」後，在終端機貼上這一行。

bash "$HOME/Downloads/YeCai-Connect-Mac.command"

配對完成後，請開著 Docker 與原來的 BiliNote。Mac 登入後會自動領取工作。

LINE 測試頻道

設定測試頻道

在這個 Railway 測試服務的 Variables 設定測試頻道的 TRIAL_LINE_CHANNEL_SECRET 與 TRIAL_LINE_ACCESS_TOKEN，並套用設定。再到同一個測試頻道的 LINE Developers 後台填入下方 Webhook URL，按 Verify 並開啟 Use webhook。

重新整理本頁，取得配對碼，在測試帳號的一對一聊天室送出。配對後即可直接分享影片。
