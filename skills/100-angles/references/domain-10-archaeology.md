# 第十域：考古/法医型运算

## #72 写作动机考古

**指令**：以考古学家的方法，追溯 {book} 的写作动机。什么经历/创伤/时代张力驱动了这本书的诞生？

**Prompt模板**：

对 {book} 执行"写作动机考古"：

1. **背景重建**：重建该书写作时的知识气候——什么样的问题在困扰那个时代？
2. **个人动因分析**：作者有哪些已知的个人经历可能驱动了这本书？
3. **学术谱系定位**：在学术谱系中，这本书是对哪个传统/争论的反应？
4. **张力识别**：这本书试图解决的核心张力/矛盾是什么？
5. **考古报告输出**：以考古报告格式输出，包含背景重建、动因分析、学术谱系定位、张力识别

## #73 读者考古

**指令**：重建 {book} 的理想读者画像。这本书是为谁写的？那个人有什么特征？

**Prompt模板**：

对 {book} 执行"读者考古"：

1. **直接证据**：书中明确提到"你"（读者）的地方在哪里？这透露了什么读者特征？
2. **知识前提推断**：作者假设读者已经掌握了哪些知识？
3. **价值观对齐推断**：作者假设读者认同哪些价值观？
4. **理想读者重建**：综合以上信息，重建理想读者的画像（职业、教育背景、价值观、问题意识）
5. **真实读者比较**：实际读者与理想读者有多大差距？这个差距如何影响了该书的传播？

## #74 概念尸检

**指令**：对 {book} 中消亡或被取代的核心概念进行尸检。这些概念为什么会"死"？取代它们的新概念是什么？

**Prompt模板**：

对 {book} 执行"概念尸检"：

1. **概念清单**：该书依赖的核心概念有哪些？
2. **概念寿命评估**：每个概念目前处于"活跃期"、"衰退期"还是"已死亡"？
3. **死亡原因分析**：如果是衰退/死亡概念，死亡原因是什么？（被反驳？被超越？语言污染？）？
4. **取代概念识别**：取代旧概念的新概念是什么？
5. **尸检报告**：以尸检报告格式输出，包含概念死亡时间线、死亡原因、取代概念

---

## #75 出版环境重建

**指令**：重建 {book} 出版时的知识气候与出版生态。出版时该领域的"知识版图"是什么样的？

**Prompt模板**：

对 {book} 执行"出版环境重建"：

1. **知识版图重建**：该书出版时，所在领域的主流范式是什么？
2. **竞争格局分析**：同代有哪些竞争性著作？它们的立场有何不同？
3. **出版生态评估**：当时的出版生态（审查制度、市场状况、学术评价机制）如何影响了该书的命运？
4. **历史节点定位**：该书的出版是否恰好出现在某个历史转折点上？
5. **环境重建报告**：以历史纪录片脚本格式输出，包含时代背景、竞争格局、出版生态、历史节点

## #76 版本差异分析

**指令**：分析 {book} 不同版本之间的演变。如果有多个版本，这个变化轨迹揭示了什么？

**Prompt模板**：

对 {book} 执行"版本差异分析"：

1. **版本清单**：该书有哪些已知版本？（初版/修订版/翻译版/普及版）？
2. **变化清单**：不同版本之间发生了哪些变化？（论点修改？删节？新增？）？
3. **变化驱动分析**：驱动这些变化的是什么？（批评反馈？作者反思？政治压力？）？
4. **"最好的版本"评估**：哪个版本最能代表该书的真实面目？
5. **版本演化报告**：以版本时间轴形式展示变化轨迹及其驱动因素

## #77 引用链追踪

**指令**：追溯 {book} 引用的知识源头。这个作者的知识谱系树有多深？追溯到多远？

**Prompt模板**：

对 {book} 执行"引用链追踪"：

1. **直接引用识别**：该书直接引用/提及了哪些主要作者？
2. **第一代祖先**：直接引用的作者是第一代知识祖先
3. **第二代祖先**：知识祖先的知识祖先是谁？（追溯两代）
4. **知识源头识别**：追溯到尽头，哪些"元思想"（无法再追溯源头的基本概念）是这本书的知识基础？
5. **谱系报告**：以知识谱系图形式展示引用链，从元思想到该书的完整知识路径
