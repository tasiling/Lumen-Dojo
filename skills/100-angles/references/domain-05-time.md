# 第五域：时间型运算

## #36 逆向因果重写

**指令**：颠倒 {book} 的时间顺序重写叙事。如果书的叙事从最后一章开始向前展开，读者会有完全不同的理解吗？这揭示了时间的哪些修辞力量？

**Prompt模板**：

对 {book} 执行"逆向因果重写"：

1. **时间线提取**：识别该书叙事的完整时间跨度（真实时间与叙事时间）
2. **逆向重写实验**：从结局倒推到开头，以"为什么会有这个结局"的视角重写
3. **叙事力量揭示**：正向叙事与逆向叙事之间的理解差异，揭示了哪些修辞力量？
4. **因果反转点识别**：书中哪些叙事选择依赖于时间顺序才能成立？
5. **逆向重写报告**：以对比格式输出"正向版本"与"逆向版本"的关键差异

## #37 考古碎片重组

**指令**：以考古学方法处理 {book}——将文本当作残片，从碎片中拼凑作者没有明说的"完整图景"。碎片之间的空白如何填补？

**Prompt模板**：

对 {book} 执行"考古碎片重组"：

1. **碎片提取**：从书中提取10-15个最具代表性的"文本碎片"（关键引文/细节/证据）
2. **碎片年代鉴定**：每个碎片属于哪个"考古层"（早期直觉/中期研究/后期修订）？
3. **碎片关系分析**：碎片之间是什么关系（直接相邻/被破坏隔离/原本相邻但后来分离）？
4. **空白填补**：碎片之间的空白（未言明的部分）应该如何填补？
5. **考古报告输出**：以考古发掘报告格式输出，包含地层图、碎片清单、重组假设

## #38 预言逆推

**指令**：如果 {book} 的内容是对未来的预言，将其作为预言来解构。当前世界处于预言的哪个节点？预言的实现路径是什么？

**Prompt模板**：

对 {book} 执行"预言逆推"：

1. **预言内容识别**：该书的论点中包含哪些对未来的预测？
2. **预言精度分类**：这是精确预言（时间地点可确定）还是模糊预言（永远可以自圆其说）？
3. **当前节点定位**：如果这是预言，我们现在处于预言时间线的哪个位置？
4. **实现路径分析**：从预言到现实，需要经过哪些步骤？哪些步骤已经发生？
5. **预言评估报告**：以预言解读报告格式输出，包含预言内容、实现程度、关键节点

## #39 半衰期分类

**指令**：分析 {book} 不同类型信息的衰减曲线。哪些内容随时间仍然有效？哪些已经过时？哪些信息有"半衰期"？

**Prompt模板**：

对 {book} 执行"半衰期分类"：

1. **信息分类**：将书中的信息分为（A）时效性（很快过时）、（B）长期有效、（C）永久有效、（D） timeless（超越时间）
2. **半衰期估算**：对每个分类估算信息衰减的速度
3. **半衰期决定因素**：哪些因素决定了信息的半衰期（技术进步？社会变化？哲学洞察？）？
4. **当前有效性评估**：在出版多年后的今天，书中的哪些内容仍然有效？
5. **半衰期图表**：以衰减曲线图形式展示不同类型信息的衰减速度

## #40 进化模拟

**指令**：以生物进化视角看待 {book} 的"模因"——它的核心思想是如何演化变异的？哪些"变种"比原始版本更成功？

**Prompt模板**：

对 {book} 的核心思想执行"进化模拟"：

1. **模因识别**：该书最核心的"模因"（可复制的思想单元）是什么？
2. **变异路径追踪**：这些模因在传播过程中经历了哪些变异？
3. **适应度评估**：在传播竞争中，哪些变种比原始版本更"适应"？
4. **自然选择分析**：什么因素决定了模因的生存？（简单性？情感共鸣？实用性？）？
5. **进化树输出**：以进化树形式展示模因的变异与分支路径

## #41 前传生成

**指令**：为 {book} 生成"前传"——在这本书所描述的世界/论点出现之前，世界是什么样的？是什么条件和事件催生了它？

**Prompt模板**：

对 {book} 生成"前传"：

1. **诞生条件识别**：这本书（或其核心论点）的诞生需要哪些必要条件？
2. **前世界描绘**：在必要条件尚未满足时，世界是什么样的？
3. **催化剂识别**：是什么事件/人物/发现充当了"催化剂"，使必要条件得以汇聚？
4. **张力积累**：在催化剂之前，矛盾/问题是如何积累的？
5. **前传叙事**：以500字叙事形式写一段"前传"——从问题积累到这本书诞生的前夜

## #42 续集生成

**指令**：为 {book} 生成"续集"——在这本书所描述的世界之后，最可能发生什么？延续本书逻辑的最直接后果是什么？

**Prompt模板**：

对 {book} 生成"续集"：

1. **趋势延伸**：该书描述的趋势如果继续发展，下一个阶段是什么？
2. **内部矛盾爆发**：该书忽视或压抑的内在矛盾，在未来会如何爆发？
3. **外部压力适应**：未来世界的哪些变化会冲击这本书的框架？
4. **续集大纲构建**：以章节大纲形式构建"续集"的可能叙事
5. **续集叙事**：以500字叙事形式写一段"续集"——从这本书之后最可能发生的事件开始
