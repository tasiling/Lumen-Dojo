# 第十四域：特殊型运算

## #95 书的墓志铭

**指令**：为 {book} 撰写墓志铭——如果这本书死去，它希望被如何记住？用一句话总结它希望留下的遗产。

**Prompt模板**：

为 {book} 撰写"墓志铭"：

1. **遗产识别**：这本书最重要的遗产是什么？
2. **死亡叙事撰写**：写一段50字的"墓志铭"——如果这本书死去，它希望被记住的方式
3. **遗产-代价评估**：这本书的遗产是否伴随着代价？（让人更智慧还是更傲慢？）？
4. **比较墓志铭**：同类书籍的墓志铭是什么？该书的独特之处如何体现？
5. **墓志铭输出**：以碑文格式输出该书的墓志铭

## #96 书的自画像

**指令**：分析 {book} 中作者如何描写自己（或自己的角色）。这是自我神化、自我贬低，还是复杂的自我博弈？

**Prompt模板**：

对 {book} 执行"自画像"分析：

1. **自我描写提取**：从书中提取所有作者自我描写的段落
2. **自我形象分类**：作者在书中扮演了什么角色？（先知/学者/普通人/英雄/受害者？）？
3. **自我叙事分析**：作者对自己故事的叙事框架是什么？（受害者叙事？英雄叙事？普通人叙事？）？
4. **自我形象评估**：这个自我形象是准确的吗？是否有所美化和扭曲？
5. **自画像报告**：以艺术评论格式输出，包含自我形象类型、叙事框架、评估

---

## #97 解毒剂处方

**指令**：为被 {book} "毒害"的读者开具"解毒剂"。这本书的毒副作用是什么？解药在哪里？

**Prompt模板**：

对 {book} 开具"解毒剂处方"：

1. **毒素识别**：这本书可能造成的"中毒"症状是什么？（过度自信？偏见加深？错误应用？）？
2. **中毒机制分析**：中毒是如何发生的？是通过哪些机制？
3. **解药配方**：什么内容/书籍/视角可以作为解毒剂？
4. **解毒疗程设计**：解毒需要多长时间？有哪些步骤？
5. **处方单**：以医疗处方格式输出，包含毒素识别、中毒机制、解药配方、解毒疗程

---

## #98 遗书撰写

**指令**：以该书作者的身份，撰写一封"遗书"——这本书想对读者说的最后一句话是什么？

**Prompt模板**：

对 {book} 撰写"遗书"：

1. **最后的话识别**：如果这是作者的最后表达机会，他最想说的是什么？
2. **遗书撰写**：以作者视角，撰写一封200字的"遗书"
3. **遗憾识别**：作者可能会对这本书留下什么遗憾？
4. **希望传承**：作者最希望读者带走的是什么？
5. **遗书输出**：以遗书格式输出，包含最后的话、遗憾、希望传承

## #99 活的尸体测试

**指令**：将 {book} 的核心框架放在今天的现实中检验。如果书的作者今天还活着，他们会如何修改这本书？

**Prompt模板**：

对 {book} 执行"活的尸体测试"：

1. **框架寿命评估**：该书的框架在今天是否仍然有效？
2. **时代差异分析**：出版时代与今天之间发生了哪些重大变化？
3. **修订建议生成**：如果作者今天重写这本书，会做出什么改变？
4. **核心幸存评估**：该书的核心论点，有多少在今天仍然成立？
5. **测试报告**：以体检报告格式输出，包含框架寿命评估、时代差异、修订建议、核心论点评估

## #100 黑箱审计

**指令**：在不知道 {book} 作者身份、声誉和背景的情况下，独立评估这本书。以一个完全不知情的读者的角度，判断这本书的真正价值。

**Prompt模板**：

对 {book} 执行"黑箱审计"：

1. **背景剥离**：暂时忘记作者身份，仅基于文本内容评估
2. **内部一致性检测**：该书内部是否自洽？
3. **证据质量评估**：书中的证据质量如何？论证逻辑是否严谨？
4. **黑箱评分**：以匿名评审员身份，给该书的论点质量打分（1-10）
5. **审计报告**：以审计报告格式输出，包含背景剥离后的评估、内部一致性检测、证据质量评估、匿名评分
