# 第八域：形式/数学型运算

## #57 拓扑分析

**指令**：分析 {book} 论证结构的拓扑形状。这个论证是一个环、一个树、一张网、还是一个流？拓扑结构如何影响论证的效力？

**Prompt模板**：

对 {book} 执行"拓扑分析"：

1. **拓扑形状识别**：全书的论证结构是什么拓扑形状？（线/树/网/环/混合）？
2. **节点分析**：拓扑中的"节点"（关键论点）是什么？它们之间的"边"是什么？
3. **连通性分析**：论证的每个部分是否连通？是否存在孤立的"孤岛论点"？
4. **拓扑稳定性**：如果移除某个节点，整个拓扑是否会分裂或崩溃？
5. **拓扑图输出**：以拓扑图形式展示论证结构（可用ASCII艺术）

## #58 对称性分析

**指令**：分析 {book} 论证中的对称与不对称。哪些论点在结构上对称？这种对称是否有意义，还是偶然的？

**Prompt模板**：

对 {book} 执行"对称性分析"：

1. **对称识别**：书中是否存在论证的对称结构？（正反论点并列？A→B与¬A→¬B？）？
2. **对称类型**：这是镜面对称、旋转对称、还是尺度对称（分形）？
3. **不对称检测**：哪些地方破坏了完美的对称？这些不对称是故意的还是无意的？
4. **对称意义评估**：对称结构是否增强了论证说服力？不对称是否揭示了真正的弱点？
5. **对称报告**：以几何图示形式展示对称与不对称结构

## #59 相变标记

**指令**：识别 {book} 论证中的"相变"临界点——在哪个时刻/论点上，书的性质发生了突变（从描述变为规范？从分析变为 prescriptions）？

**Prompt模板**：

对 {book} 执行"相变标记"：

1. **相识别**：该书处于哪些认知"相态"？（描述相/分析相/规范相/情感相）？
2. **相变点定位**：这些相之间的转变发生在哪些具体段落？
3. **相变性质分析**：相变是平滑过渡还是突变？突变处是否存在逻辑跳跃？
4. **相变驱动因素**：什么驱动了相变？（证据积累？修辞需要？世界观假设？）？
5. **相变图谱**：以温度-压力图形式标注相变点，横轴为论点进展，纵轴为"相态温度"

## #60 递归自检

**指令**：检查 {book} 是否被自己的论证所"吞噬"。它是否在批判某种思维方式时，使用了同样的思维方式？

**Prompt模板**：

对 {book} 执行"递归自检"：

1. **自噬检测**：该书是否在批判某种思维方式或论证方式时，使用了同样的方式？
2. **层次分析**：书的论证讨论了多少个层次？最高层次是什么？
3. **自指结构识别**：书是否包含自指结构？（"这本书论证了..."）？
4. **自噬后果评估**：如果该书的论证为真，它本身是否也会被同样的标准审判？
5. **递归自检报告**：以程序流程图形式展示递归结构，标注自噬点

## #61 压缩极限

**指令**：分析 {book} 的信息压缩极限。这本书能被压缩到多小而不丧失其核心价值？

**Prompt模板**：

对 {book} 执行"压缩极限"分析：

1. **核心层识别**：该书的最内核（绝对不可压缩的部分）是什么？
2. **渐进压缩实验**：分别以10%、25%、50%的压缩率复述该书，测试各阶段的损失
3. **压缩比评估**：在不同压缩比下，书的"功能"（说服/教育/审美）损失程度如何？
4. **极限识别**：该书的绝对压缩极限是多少？
5. **压缩报告**：以压缩金字塔形式展示不同压缩层级及其保留内容

## #62 冗余定位

**指令**：识别 {book} 中可删除的部分——哪些内容删除后不影响核心论点，甚至可能改善书的效力？

**Prompt模板**：

对 {book} 执行"冗余定位"：

1. **冗余识别**：书中哪些段落/章节可以被完全删除而不影响核心论点？
2. **冗余分类**：冗余属于（A）案例堆砌、（B）重复论证、（C）背景铺垫、（D）防御性段落？
3. **冗余价值评估**：某些冗余是否有审美或情感价值，而非纯逻辑价值？
4. **删除实验**：删除冗余后，书的整体阅读体验会发生什么变化？
5. **冗余地图**：以书的章节地图形式标注冗余位置，区分"逻辑冗余"与"审美冗余"

## #63 分形检测

**指令**：检测 {book} 的论证是否具有分形特征——局部结构是否与整体结构自相似？子论点是否重复了整体的论证模式？

**Prompt模板**：

对 {book} 执行"分形检测"：

1. **分形识别**：书的子结构（章节/段落）是否重复了整体的论证模式？
2. **分形层级**：书中有多少个分形层级？
3. **分形保真度**：子结构与整体结构的自相似程度有多高？
4. **分形意义**：分形结构是作者有意识的修辞策略，还是无意识的认知习惯？
5. **分形图谱**：以嵌套图形式展示分形结构，标注每个层级的自相似度

## #64 博弈重构

**指令**：以博弈论框架重构 {book} 中的决策场景。书中的角色之间是什么博弈关系？博弈的均衡在哪里？

**Prompt模板**：

对 {book} 执行"博弈重构"：

1. **博弈识别**：书中描述了哪些决策场景？参与者是谁？
2. **博弈结构建模**：为每个决策场景建立博弈矩阵（2×2或其他）
3. **均衡分析**：每个博弈的纳什均衡在哪里？是否存在占优策略？
4. **博弈修正分析**：如果博弈条件改变，均衡会如何变化？
5. **博弈重构报告**：以博弈树/矩阵图形式展示决策结构与均衡分析
