# 第三域：应力测试型运算

## #21 极端读者攻击

**指令**：想象一个对 {book} 主题最不友好、最刁钻的读者，他们会如何攻击这本书？以最刁钻反对者的身份，逐点反驳全书的每个核心论点。

**Prompt模板**：

你是一个对 {book} 主题极度不友好的刁钻读者。请执行以下反驳攻击：

1. **最强反驳构建**：针对书中最薄弱的3个论点，构建最有力的反驳
2. **预设攻击**：攻击这本书的哪些预设是不证自明的？哪些是作者偷偷塞进来的？
3. **案例攻击**：书中的案例能否找到反例？过度依赖个别案例的地方在哪里？
4. **边界攻击**：这个论证在哪些情况下会崩溃？边界条件是什么？
5. **反驳报告**：以陪审团辩护格式输出，包含控方论点、证据、结论

## #22 基础假设反转

**指令**：将 {book} 最重要的基础假设反转，然后从反面的假设出发，重建一套自洽的替代论证。这本书的结论在什么假设下会完全翻转？

**Prompt模板**：

对 {book} 执行"基础假设反转"：

1. **基础假设识别**：找出这本书最基础的3个假设（移除则全书崩塌）
2. **反转操作**：将每个假设反转（如果A，则变为如果非A）
3. **替代世界构建**：从反转的假设出发，重建一套替代性论证
4. **替代结论推导**：在反转假设下，最可能得出的结论是什么？
5. **对比报告**：以对照表形式展示原假设→反转假设→替代结论

---

## #23 历史穿越测试

**指令**：将 {book} 置于不同的历史时期测试——它会在每个时代同样有效吗？哪里是时代的滤镜？哪里是跨时代的普适洞察？

**Prompt模板**：

将 {book} 置于不同历史场景进行测试：

1. **时代过滤器识别**：这本书的哪些论点受到其写作时代的深刻影响？
2. **历史穿越测试**：选择3个不同历史时期，测试书中论点的适用性
3. **时代不变内核**：哪些论点是跨时代的普适洞察？
4. **时代局限边疆**：书的论证在哪个边界之外会完全失效？
5. **历史坐标报告**：以时间轴形式标注每个论点的有效时间范围

---

## #24 反向工程

**指令**：从书的最终结论出发，逆向推演：为了到达这个结论，需要哪些前提、证据和论证路径？这些前提和路径在书中是否真的得到了支撑？

**Prompt模板**：

对 {book} 执行"反向工程"：

1. **终点定位**：该书最重要的结论是什么？
2. **路径逆向追溯**：为了到达这个结论，需要经过哪些论证步骤？
3. **前提逆向追溯**：每个论证步骤需要什么前提？这些前提是否得到支撑？
4. **缺口检测**：是否存在从前提到结论的逻辑缺口？
5. **逆向工程报告**：以流程图形式展示从结论到前提的逆向路径

---

## #25 边界条件探测

**指令**：探测 {book} 论证的边界条件——超出哪个范围书中的结论就不再成立？寻找"适用性边疆地图"。

**Prompt模板**：

对 {book} 执行"边界条件探测"：

1. **参数识别**：书中论证依赖哪些关键参数（规模、时间、空间、群体特征等）？
2. **边界实验**：对每个参数进行边界测试——在什么阈值下结论开始失效？
3. **边界类型分类**：失效是渐进的（逐渐失效）还是突变的（相变式失效）？
4. **安全区标注**：在哪些参数范围内，书中的论证是安全可靠的？
5. **边界地图输出**：以地图形式标注适用性边界与安全区

## #26 沉默者的声音

**指令**：识别 {book} 中被压制、忽视或边缘化的声音。如果这些人（群体、视角、传统）有机会发声，他们会如何回应这本书？

**Prompt模板**：

识别 {book} 中被压制的声音：

1. **沉默者识别**：这本书没有给谁发言权？哪些群体/视角在书中是"隐形"的？
2. **压制机制分析**：这些沉默是被主动压制（明确排斥）还是被动忽视（结构性地没有被考虑）？
3. **声音重建**：以被压制者的身份，写一段对这本书的回应
4. **替代框架构建**：从被压制者的视角，这个问题的不同框架是什么？
5. **沉默者报告**：以采访记录格式输出，包含沉默者画像、回应、替代框架

---

## #27 反事实推演

**指令**：以 {book} 的核心论点是前提，进行"如果X没有发生"的反事实推演。如果这个论点的前提条件没有成立，世界会是什么样？

**Prompt模板**：

对 {book} 的核心论点进行反事实推演：

1. **关键反事实选择**：该书最重要的因果论点是什么？
2. **反事实构建**：如果这个因果关系不成立，世界会是什么样？
3. **反事实链条**：在这个反事实世界中，哪些后续事件会发生变化？
4. **替代历史写作**：写一段200字的"替代历史"——在这个反事实世界中发生了什么
5. **反事实地图**：以分支图形式展示真实历史与反事实历史的分叉点

2. **预言验证**：基于今天的知识，哪些预言已经得到验证？哪些失败了？
3. **历史角色评估**：这本书在过去十年中扮演了什么角色——催化剂？绊脚石？还是被遗忘？
4. **判决构建**：基于历史记录，陪审团会如何判决这本书的价值？
