# 第四域:网络/关系型运算

## #29 概念图谱

**指令**:绘制 {book} 中所有核心概念的关系网络图。概念之间是什么关系(因果/包含/对立/平行/衍生)?哪些概念是中心节点?哪些是边缘概念?

**Prompt模板**:

对 {book} 构建概念图谱:

1. **节点识别**:从全书中提取15-20个核心概念作为节点
2. **关系类型标注**:为每对概念之间的关系类型打标签(因果→、包含∈、对立↔、平行∥、衍生↳)
3. **中心性计算**:哪些概念是网络的中心(被最多其他概念引用)?哪些是边缘概念?
4. **社区检测**:这些概念是否形成若干"社区"(紧密关联的概念群)?
5. **概念图谱输出**:以网络图形式展示(可用文本箭头图表表示)

## #30 影响涟漪

**指令**:分析 {book} 的思想对后世的影响涟漪。它影响了谁?谁在它的基础上发展了新的思想?谁在反抗它的影响?

**Prompt模板**:

对 {book} 追踪"影响涟漪":

1. **第一波涟漪**:该书直接影响了哪些人/作品?(同时代与紧接着的后世)
2. **第二波涟漪**:受影响者的后续发展是什么?
3. **反抗涟漪**:谁在主动反抗这本书的影响?他们的反驳是什么?
4. **衰减分析**:这本书的影响力是随距离衰减还是存在某种"超距作用"?
5. **涟漪地图**:以同心圆扩散图形式标注影响的范围与强度

## #31 思想谱系

**指令**:绘制 {book} 与历史上思想家的对话关系图。谁是它的思想祖先(影响了它)?谁是它的同代对话者(与它同时代的思想家)?谁是它的思想后代(它影响了谁)?

**Prompt模板**:

对 {book} 构建思想谱系:

1. **祖先识别**:找出该书的知识祖先(3-5个最重要的思想来源)
2. **同代对话者**:同时代有哪些思想家在讨论同一个问题?
3. **后代映射**:谁在知识上"继承"了这本书的遗产?
4. **对话内容**:该书与其思想祖先/同代对话者具体在讨论什么问题?
5. **谱系图输出**:以家族树形式展示思想谱系(祖先在上,后代在下)

---

## #32 引用网络

**指令**:分析 {book} 与其他书籍之间的引用/对话关系。它引用了谁?谁引用了它?哪些书是它的对话伙伴?

**Prompt模板**:

对 {book} 分析引用网络:

1. **引用来源分析**:该书主要引用了哪些类型的书籍/作者?引用频率如何?
2. **引用策略分析**:该书引用他人的方式是什么(支持?反驳?继承?修正?)?
3. **被引用分析**:这本书被哪些后续书籍引用?被引用的核心观点是什么?
4. **沉默引用**:该书没有提到但应该提到的著作有哪些?
5. **引用网络图**:以网络图形式展示引用关系(进=被引用,出=引用他人)

## #33 术语地图

**指令**:绘制 {book} 的核心术语语义网络。同一个词在不同语境中的含义是否发生变化?核心术语与其他术语的语义关系是什么?

**Prompt模板**:

对 {book} 构建术语语义地图:

1. **核心术语提取**:列出全书10-15个最重要的术语
2. **定义分析**:每个核心术语在书中是如何被定义的?是否有一致的使用?
3. **语义漂移检测**:同一术语在不同章节/语境中的含义是否发生了漂移?
4. **语义关系映射**:术语之间是什么关系(同义/反义/上下位/相关)?
5. **术语地图输出**:以语义网络图形式展示术语关系

## #34 逻辑依赖树

**指令**:绘制 {book} 论证前提的逻辑依赖树。从最终结论出发,追溯每个结论依赖哪些前提,每个前提又依赖哪些更底层的前提。

**Prompt模板**:

对 {book} 构建逻辑依赖树:

1. **最终结论确定**:该书最重要的结论是什么?
2. **一级依赖识别**:这个结论直接依赖哪些前提/论点?
3. **递归追溯**:每个一级依赖本身又依赖哪些更底层的前提?
4. **底层公理定位**:依赖树的"根"在哪里——哪些是最底层、不依赖其他前提的公理?
5. **依赖树输出**:以树状图形式展示逻辑依赖结构,标注每个节点的稳固性

## #35 权力结构图

**指令**:分析 {book} 中人物(或概念)之间的权力关系网络。谁拥有权力?权力的来源是什么?权力关系是如何随时间变化的?

**Prompt模板**:

对 {book} 分析权力结构:

1. **权力节点识别**:书中主要的权力拥有者/中心是谁?
2. **权力来源分析**:每个权力的来源是什么(暴力?知识?制度?资本?)?
3. **权力关系映射**:权力者与权力者之间是什么关系(联盟/竞争/依附/压制)?
4. **权力流动分析**:书中的叙事过程中,权力关系是否发生了位移?
5. **权力结构图输出**:以组织图形式展示权力关系,标注权力流向与强度
