# 第一域：解剖型运算

## #01 骨骼提取

**指令**：剥离书的修辞外壳与案例堆砌，将其重写为纯形式化命题链。识别全书赖以成立的核心命题，并追问：命题之间的逻辑关系是什么？是否存在未被明言的隐藏前提？

**Prompt模板**：

请分析 {book}，执行以下"骨骼提取"操作：

1. **识别核心命题**：从全书中提炼出 5-8 个核心命题（不包含例证和故事）
2. **命题链构建**：用箭头表示命题之间的逻辑依赖关系（"因此"、"然而"、"故"）
3. **隐藏前提标注**：标注每个命题背后的隐性假设（未被言明但必须为真的前提）
4. **公理系统检测**：识别这些命题共同依赖的底层公理
5. **形式化输出**：将全书的论证结构压缩为一行数学式（如：A + B → C，但非D）

请以结构化格式输出，包括：命题列表、逻辑关系图（文本形式）、隐藏前提清单、公理系统描述。

## #02 暗物质测绘

**指令**：识别并标注作者未明言的公理系统、隐性价值判断、以及文本中被压制的思想维度。这些"暗物质"虽然不在书中显性存在，但塑造了书的全部可见结构。

**Prompt模板**：

对 {book} 执行"暗物质测绘"：

1. **第一层暗物质（价值公理）**：识别作者未明说但默认的价值观（如：进步是好的？个人比集体重要？理性高于情感？）
2. **第二层暗物质（存在性公理）**：识别作者默认的世界观前提（如：时间是线性的？因果律普遍成立？）
3. **第三层暗物质（方法论公理）**：识别作者默认的认识论（如：经验是知识的唯一来源？数学是自然的语言？）
4. **第四层暗物质（沉默维度）**：识别这本书选择不讨论的主题——为什么作者在这些话题面前"失明"？
5. **引力场分析**：这些暗物质如何扭曲了书中可见的论证结构？

## #03 删节复原

**指令**：反向工程一本书——从出版物的最终形态倒推：哪些内容被删掉了？编辑/作者/审查者的刀落在哪里？这些删节揭示了什么被压制的声音？

**Prompt模板**：

对 {book} 执行"删节复原"考古：

1. **空白检测**：通过书的结构裂缝（章节不连贯处、论点跳跃处、突然结尾处）识别删节信号
2. **动机推断**：为什么这些内容被删？自我审查？编辑要求？法律风险？论点修正？
3. **幽灵章节重建**：基于结构分析和已知背景，重建被删章节的合理内容
4. **被压制声音识别**：被删的内容原本可能代表谁的利益/视角？
5. **删节考古报告**：以考古报告格式输出（发现位置→推断内容→删节动机→被压制声音）

## #04 恐惧扫描

**指令**：标注书中论证的"恐惧驱动点"——作者害怕什么观点/结论/反驳？通过论证的异常加重点、过度论证点、以及刻意回避处识别恐惧图谱。

**Prompt模板**：

对 {book} 执行"恐惧扫描"：

1. **过度论证点识别**：哪个论点被论证得特别用力？用力过度往往暗示内心恐惧
2. **论证漏洞标注**：作者刻意没有正面回应哪些反驳？
3. **幽灵恐惧定位**：书中有哪些"不提反面论据"的结构性沉默？
4. **恐惧类型分类**：作者害怕的是（A）被驳倒、（B）被误解、（C）被应用于错误场景、（D）伤害特定群体？
5. **恐惧地图输出**：用文本图表标注全书的恐惧驱动点与恐惧类型

## #05 动词骨架

**指令**：从书中提取所有关键动作（动词），剥去名词外壳，找到驱动全书运转的原始动作序列。这些动词的排列方式揭示了书的思维 DNA。

**Prompt模板**：

对 {book} 执行"动词骨架"提取：

1. **动词提取**：从书中提取所有关键动词（特别是描述行动、变化、关系的词）
2. **动作序列还原**：将这些动词按发生的逻辑顺序排列，形成书的"动作电影"
3. **主语分析**：每个关键动作的执行者是谁？他们之间是什么关系？
4. **思维DNA揭示**：这些动词的排列方式揭示了作者什么样的思维模式？（是"控制"型？"观察"型？"对抗"型？）
5. **动词骨架输出**：以流程图或表格形式展示动作序列与思维DNA

## #06 矛盾晶体

**指令**：识别书中表面或深层的矛盾，将其转化为洞察发生器而非缺陷报告。矛盾处往往是真相浮出水面的地方。

**Prompt模板**：

对 {book} 执行"矛盾晶体"分析：

1. **矛盾识别**：找出书中 3-5 个最核心的内在矛盾（可以是论点矛盾、价值矛盾、叙事矛盾）
2. **矛盾结构分析**：这是"表面矛盾"（可化解）还是"深层矛盾"（不可化解的结构性张力）？
3. **矛盾年龄检测**：这个矛盾是原生的（从一开始就存在）还是后生的（写作过程中产生的）？
4. **洞察转化**：将每个矛盾转化为一个强力问题或洞察
5. **矛盾晶体报告**：以晶体结构图形式展示矛盾的多个切面及其折射的洞察

**指令**：标注全书论证的"引力井"（核心论点）、"真空区"（刻意回避的话题）、以及"拉格朗日点"（不同引力场交界处的微妙平衡点）。

**Prompt模板**：

对 {book} 执行"重力分析"：

1. **引力井定位**：全书的哪个论点吸引了最多论证资源？这是引力中心
2. **真空区标注**：有哪些话题在书的有引力范围之外？为什么作者有意回避？
3. **拉格朗日点识别**：在哪些位置，不同的引力场（论点）处于动态平衡？
4. **逃逸速度计算**：读者需要多少认知能量才能从引力井逃逸到独立思考？
5. **引力场图输出**：以天体物理隐喻图形式展示全书的引力结构

## #10 信噪分离

**指令**：从信息论视角，分析书中"信号"（独特洞察）与"噪声"（填充、重复、已知信息）的比例，输出信噪比图谱。

**Prompt模板**：

对 {book} 执行"信噪分离"分析：

1. **信号识别**：书中哪些内容包含真正的独特信息（非已知、非共识、非常识）？
2. **噪声分类**：噪声来源是（A）修辞填充、（B）重复论证、（C）已知信息重述、（D）无关案例？
3. **信噪比估算**：对每个章节估算信号/噪声比，以百分比表示
4. **最优压缩率**：该书可以被压缩到原始篇幅的百分之几而不损失有效信息？
5. **信噪比图谱输出**：以信息论图谱形式展示每个章节的信噪比
