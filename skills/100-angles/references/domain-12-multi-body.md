# 第十二域：多体碰撞型运算

## #85 三体碰撞

**指令**：让 {book} 与另外两本完全不同领域的书籍进行"思想碰撞"。三本书的洞见在碰撞中会产生什么涌现？

**Prompt模板**：

对 {book} 执行"三体碰撞"：

1. **碰撞伙伴选择**：选择2本与该书完全不同领域的书籍
2. **核心洞见提取**：为每本书提炼1-2个核心洞见
3. **碰撞点识别**：三本书的洞见之间存在什么张力和互补？
4. **碰撞模拟**：以多轮对话形式模拟三本书的"思想碰撞"（每人3-5轮）
5. **涌现提炼**：碰撞产生了什么单一书本中不存在的全新洞察？
6. **碰撞报告**：以实验报告格式输出，包含碰撞伙伴、碰撞点、碰撞过程、涌现洞察

## #86 敌意合成

**指令**：将 {book} 与一本观点完全相反的书强行"融合"。矛盾的书能产生什么？这种敌意合成是否有意义？

**Prompt模板**：

对 {book} 执行"敌意合成"：

1. **敌手识别**：与该书观点最相反的书是什么？
2. **核心冲突定位**：两书之间最核心的不可调和冲突是什么？
3. **合成实验**：强制将两本书的核心洞见融合，会产生什么？
4. **合成评估**：合成产物是有意义的新洞见，还是逻辑上的怪物？
5. **合成报告**：以化学实验报告格式输出，包含反应物、反应条件、生成物、评估

## #87 学术会议模拟

**指令**：模拟一场多学科专家对 {book} 的联合评审会议。不同学科的专家会关注什么？他们会得出什么共同结论？

**Prompt模板**：

对 {book} 模拟"学术会议"：

1. **专家选择**：选择3-5个不同学科的专家（每个专家关注一个独特视角）
2. **专家发言生成**：为每个专家撰写评审意见（300字）
3. **交叉质疑环节**：不同专家之间的分歧在哪里？他们如何相互质疑？
4. **共识提炼**：会议最终达成了哪些共识？
5. **学术会议记录**：以学术会议记录格式输出，包含与会专家名单、各专家发言、交叉质疑、共识结论

## #88 法庭辩论模拟

**指令**：将 {book} 置于"法庭辩论"结构中——原告、被告、法官。哪方论点更有说服力？

**Prompt模板**：

对 {book} 模拟"法庭辩论"：

1. **角色分配**：原告（该书的批评者）vs 被告（该书的辩护者）vs 法官（中立评估者）
2. **原告论点**：批评者提出的3个最强论点
3. **被告论点**：辩护者提出的3个最强论点
4. **交叉询问**：原被告之间的交叉询问
5. **法官判决**：法官的综合评估与最终判决
6. **法庭辩论记录**：以法庭笔录格式输出

## #89 多元宇宙分支

**指令**：为 {book} 的核心前提构建"多元宇宙"——如果这个前提为真，其他可能世界中会发生什么？

**Prompt模板**：

对 {book} 执行"多元宇宙分支"：

1. **分支点识别**：该书最核心的分支假设是什么？（"如果X为真"）？
2. **世界线A**：在这个假设成立的世界，会发生什么？（书中的世界）
3. **世界线B**：在这个假设不成立的世界，会发生什么？
4. **世界线C**：在这个假设以不同方式成立的其他世界，会发生什么？
5. **分支图输出**：以分支树图形式展示多元宇宙图景
