# 第十三域：涌现型运算

## #90 高频词汇解码

**指令**：超越简单的词频统计，识别 {book} 中真正高频出现的深层语言模式。这些模式揭示了作者什么样的思维惯性？

**Prompt模板**：

对 {book} 执行"高频词汇解码"：

1. **深层模式识别**：超越词频，识别真正高频出现的语义模式（概念组合、修辞结构、论证策略）
2. **思维惯性分析**：这些模式揭示了作者什么样的思维惯性或认知偏见？
3. **语言无意识识别**：哪些语言选择是作者无意识的，而非刻意为之？
4. **模式-内容对照**：这些语言模式与其核心内容之间是什么关系？（模式强化内容？模式消解内容？）？
5. **解码报告**：以符号学分析报告格式输出，包含深层模式清单、思维惯性分析、认知偏见评估

## #91 断裂点定位

**指令**：识别 {book} 论证叙事中的逻辑断裂、叙事跳跃或推理断层。这些断裂是作者的错误，还是刻意为之的省略？

**Prompt模板**：

对 {book} 执行"断裂点定位"：

1. **断裂识别**：在论证链条中，哪里出现了推理跳跃？
2. **断裂类型分类**：这是（A）逻辑断裂（跳过了推理步骤）、（B）叙事断裂（跳过了事件）、（C）修辞断裂（跳过了敏感话题）？
3. **断裂意图判断**：这个断裂是作者的无心之失，还是刻意为之？
4. **断裂修复实验**：如果我们"修复"这个断裂，论证会更强还是更弱？
5. **断裂地图**：以行军地图形式标注书中的断裂点，标注断裂类型和意图判断

## #92 主题共振

**指令**：分析 {book} 跨章节的主题共鸣。哪些主题在不同章节中以不同面目反复出现？这种共振揭示了什么？

**Prompt模板**：

对 {book} 执行"主题共振"分析：

1. **主题识别**：从各章节中提取核心主题词/主题群
2. **共振检测**：哪些主题在多个章节中以不同面目反复出现？
3. **共振强度分析**：共振是强的（直接重复）还是弱的（暗示性重复）？
4. **共振意义评估**：主题共振是否形成了全书的无意识叙事？
5. **共振地图**：以共振图形式展示跨章节的主题关联，标注共振强度和意义

## #93 情感曲线

**指令**：绘制 {book} 的读者情感旅程图。读者在阅读过程中的情感如何起伏？哪些段落令人振奋？哪些令人沮丧？

**Prompt模板**：

对 {book} 绘制"情感曲线"：

1. **情感节拍识别**：识别书中主要的情感节拍（振奋/困惑/沮丧/惊叹/愤怒/释然）
2. **情感曲线绘制**：以折线图形式绘制读者情感的完整旅程
3. **情感峰值分析**：哪些段落创造了最强烈的情感反应？为什么？
4. **情感-论证关系**：情感变化与论证进展之间是什么关系？（情感为论证服务？论证服从情感？）？
5. **情感曲线图**：以情感折线图形式输出，横轴为阅读进度，纵轴为情感强度

## #94 元叙事追踪

**指令**：追踪 {book} 中关于叙事本身的叙事层。这本书是否在讲述一个关于"如何讲故事"的故事？

**Prompt模板**：

对 {book} 执行"元叙事追踪"：

1. **元叙事识别**：该书是否包含关于叙事本身的叙事？（关于讲故事的故事）？
2. **叙事层次分析**：全书有多少个叙事层？（底层故事/元叙事/超元叙事）？
3. **层次穿透分析**：不同叙事层之间是如何相互影响的？
4. **元叙事意图判断**：元叙事层面是有意为之还是无意识流露？
5. **元叙事报告**：以嵌套图形式展示叙事层次，标注每个层次的内容和穿透关系
