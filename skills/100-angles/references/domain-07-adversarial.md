# 第七域：对抗型运算

## #51 最强反驳

**指令**：站在最刁钻反对者的角度，为 {book} 撰写最强反驳。这个反驳必须是这本书最害怕的论点，而不是最容易驳斥的稻草人。

**Prompt模板**：

对 {book} 执行"最强反驳"构建：

1. **最强反驳点识别**：这本书最脆弱的地方在哪里？什么论点能最有力地动摇它？
2. **反驳构建**：以最刁钻反对者的身份，撰写一段500字的强反驳
3. **反驳策略分析**：反驳者使用了什么策略？（攻击前提？攻击推论？攻击边界？）？
4. **反驳有效性评估**：这个反驳是否真的有效？作者应该如何回应？
5. **反驳报告**：以辩论稿格式输出，包含反驳内容、策略分析、反驳评估

## #52 死敌对话录

**指令**：让 {book} 与其历史上最有力的"思想死敌"进行对话。如果这本书能与它最强大的对手展开真诚对话，会产生什么？

**Prompt模板**：

对 {book} 构建"死敌对话录"：

1. **死敌识别**：谁是该书最有力的思想对手？（与其论战最激烈的思想家）
2. **核心分歧定位**：两者之间最核心的不可调和分歧是什么？
3. **对话场景构建**：设计一个两人对话的场景，每人3-5轮
4. **对话洞察提炼**：通过对话，双方是否产生了超越原有立场的洞察？
5. **对话录输出**：以戏剧对话格式输出，包含场景设置、对话内容、洞察总结

---

## #53 检察官摘要

**指令**：以陪审团起诉书格式，为 {book} 撰写一份"起诉书"。如果这本书必须接受陪审团审判，罪名是什么？

**Prompt模板**：

对 {book} 撰写"检察官摘要"：

1. **罪名列举**：以陪审团可理解的方式，列举该书的3-5项"罪名"
2. **证据呈现**：为每项罪名提供书中的"证据"
3. **陪审团可读性**：以普通读者（非专家）视角，评估这些罪名的可理解性
4. **辩护要点预测**：作者最可能的辩护策略是什么？
5. **起诉书输出**：以法律起诉书格式输出，包含罪名列表、证据、量刑建议

---

## #54 误用档案

**指令**：记录 {book} 被误读、滥用或扭曲的方式。这本书最常见的误解是什么？哪些"粉丝"或"批评者"以最扭曲的方式使用它？

**Prompt模板**：

对 {book} 建立"误用档案"：

1. **误用类型分类**：误用主要分为（A）过度简化型、（B）断章取义型、（C）立场盗窃型、（D）情境错位型？
2. **误用案例收集**：收集1-3个最具代表性的误用案例
3. **误用原因分析**：为什么读者会误用这本书？是书的表达问题还是读者的问题？
4. **预防建议**：作者/后来者如何能减少这本书被误用的可能性？
5. **误用档案**：以医学档案格式输出，包含误用类型、案例、原因分析、预防建议

## #55 盲区报告

**指令**：系统分析 {book} 作者的认知盲区。哪些问题是作者从根本上没有能力看到的？

**Prompt模板**：

对 {book} 撰写"盲区报告"：

1. **背景盲区识别**：作者的教育背景、专业训练如何限制了他看到的问题？
2. **时代盲区识别**：作者所处时代的局限如何影响了认知视野？
3. **性格盲区识别**：作者的性格特征（过度自信？回避争议？）如何造成了盲区？
4. **盲区补偿分析**：哪些后续研究者已经补偿了这些盲区？
5. **盲区报告**：以医学诊断报告格式输出，包含盲区类型、原因分析、影响评估、补偿状态

---

## #56 时代偏见审计

**指令**：审计 {book} 中属于特定时代的偏见。作者的哪些观点今天已经不可接受？哪些观点在当年是激进的，今天变成了常识？

**Prompt模板**：

对 {book} 执行"时代偏见审计"：

1. **时代偏见识别**：该书中有哪些今天看来明显属于特定时代的偏见？
2. **偏见分类**：偏见属于（A）科学错误、（B）价值观偏见、（C）事实偏见、（D）语言偏见？
3. **当时激进性评估**：这些观点在出版时是保守的还是激进的？
4. **可分离性分析**：书的有效洞察是否可以从时代偏见中分离出来？
5. **时代偏见报告**：以审计报告格式输出，包含偏见清单、分类、激进性评估、可分离性分析
