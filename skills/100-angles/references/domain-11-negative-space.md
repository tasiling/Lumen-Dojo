## #78 沉默目录

**指令**：编制 {book} 的"沉默目录"——这本书没有说、但不得不说的内容。这些沉默不是随意的，它们揭示了什么是这本书无法面对的。

**Prompt模板**：

对 {book} 执行"沉默目录"编制：

1. **沉默类型分类**：书的沉默属于（A）结构性沉默（整个主题被忽略）、（B）选择性沉默（某些观点被选择性忽略）、（C）修辞性沉默（提到但不展开）？
2. **沉默代价分析**：这些沉默的代价是什么？（遗漏了哪些重要视角？）？
3. **沉默原因推断**：作者为什么在这些话题面前沉默？（恐惧？能力局限？审查？策略性忽略？）？
4. **沉默放大实验**：如果这些沉默被大声说出来，会如何改变这本书的面貌？
5. **沉默目录输出**：以目录格式输出每个沉默条目，包含沉默位置、沉默类型、沉默原因、沉默代价

## #79 影子书

**指令**：以 {book} 中被压制的视角/声音，撰写"影子书"——如果被压制的声音有机会说话，他们会说些什么？

**Prompt模板**：

对 {book} 撰写"影子书"：

1. **压制识别**：这本书压制了哪些声音？这些声音的立场是什么？
2. **最强势声音选择**：选择1-2个被压制最严重的声音，作为影子书的主角
3. **影子书撰写**：以300-500字，从被压制者的视角重写书中最重要的一个场景或论点
4. **对比分析**：影子书的叙述与原书相比，揭示了什么不同的真相？
5. **影子书片段**：以独立章节格式输出影子书片段

## #80 失踪章节

**指令**：识别并重建 {book} 中因审查、自我审查或策略性忽略而"消失"的章节。这些失踪章节本应讨论什么？

**Prompt模板**：

对 {book} 执行"失踪章节"重建：

1. **失踪信号识别**：书中有哪些突然的话题中断、刻意绕开、或论证跳跃暗示了失踪内容？
2. **失踪章节类型推断**：失踪章节可能属于哪类？（政治敏感？商业利益？自我保护？学术压力？）？
3. **重建基础**：基于书中的暗示和已知背景，重建失踪章节的合理内容
4. **重建文本撰写**：以300-500字写一段"失踪章节"
5. **失踪章节报告**：以档案格式输出，包含失踪信号、重建基础、重建文本、影响评估

## #81 边界守卫者

**指令**：识别 {book} 中划定"不可说"边界的隐性规则。这本书通过什么机制告诉你什么是不可以讨论的？

**Prompt模板**：

对 {book} 执行"边界守卫者"分析：

1. **边界识别**：这本书在哪些话题上划定了"不可说"的边界？
2. **边界守卫机制**：边界通过什么机制维护？（幽默化解？措辞模糊？历史化处理？）？
3. **越界风险分析**：如果读者越界（提出边界外的问题），会有什么风险？
4. **边界历史**：这些边界是作者设定的，还是继承自他所处的知识传统？
5. **边界守卫报告**：以安保报告格式输出，包含边界位置、守卫机制、越界风险、历史分析

## #82 恐怖事物的礼节

**指令**：分析 {book} 如何以"礼节"的方式处理禁忌话题——通过特定的修辞策略，把真正恐怖的事物包装得可以接受。

**Prompt模板**：

对 {book} 执行"恐怖事物的礼节"分析：

1. **恐怖识别**：书中真正令人不安的核心主张是什么？
2. **礼节包装识别**：这个主张被如何包装以显得可接受？（学术语言？幽默化解？历史化？）？
3. **礼节机制分析**：具体使用了哪些"礼节策略"？
4. **裸恐怖还原**：去掉礼节包装后，这个主张的"裸面目"是什么？
5. **礼节报告**：以医学病理报告格式输出，包含恐怖识别、礼节包装机制分析、裸面目还原

## #83 未问的问题

**指令**：识别 {book} 的作者应该提出、但没有提出的问题。这些问题的存在揭示了什么样的认知盲区？

**Prompt模板**：

对 {book} 执行"未问的问题"生成：

1. **问题缺口识别**：在作者的论证链条中，有哪些逻辑上应该被追问、但没有被追问的问题？
2. **问题类型分类**：未问的问题属于（A）方向性问题（你研究错方向了）、（B）方法论问题（你用什么方法都不重要）、（C）前提问题（你的前提本身有问题）、（D）影响问题（你的发现会导致什么后果）？
3. **问题价值评估**：每个未问的问题的价值有多大？
4. **问题生成输出**：以问题清单格式输出5-10个未问的问题，每个问题附类型和价值评估

## #84 对手缺席

**指令**：分析 {book} 中"对手缺席"的现象——那些本应被认真对待的对手论点，为什么没有在书中得到应有的呈现？

**Prompt模板**：

对 {book} 执行"对手缺席"分析：

1. **缺席识别**：有哪些重要的反对论点/学派在书中没有被公平呈现？
2. **缺席原因推断**：这些对手缺席的原因是什么？（作者不知道？故意忽略？简化处理？）？
3. **对手补充构建**：如果给这些"缺席的对手"公平的发言机会，他们会如何反驳该书？
4. **对话重建**：以辩论格式重建作者与缺席对手的公平对话
5. **对手缺席报告**：以失踪人口报告格式输出，包含缺席者画像、缺席原因、公平对话重建
