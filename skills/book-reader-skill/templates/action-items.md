## ⚠️ 自查——这份清单是不是"假的"？

Adler 警告读者有一种自欺：**"让别人去做，我们会说，这就算是交待了。"**

对照检查：
- [ ] 以上每一条行动的**主语是我自己**（不是"大家应该"、"别人应该"）
- [ ] 以上每一条都**有具体时间 / 触发条件**，不是"有空我就做"
- [ ] 以上每一条都是**我真的会做的**，不是我觉得"应该做但其实不会做"的
- [ ] 我已经在日历 / todo / 习惯 app 里**落地**了这些行动

如果任何一项 ❌ → 删掉或改写这条，别自欺。
