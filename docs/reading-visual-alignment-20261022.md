# 閱讀筆記視覺對齊 — 2026-10-22

依使用者要求，書架、單本書閱讀、洞察卡片庫、今日回訪沿用野採已確認的蜂蜜視覺：桃色／淡黃／薄荷漸層、深藍文字、白卡、線條 SVG 圖示、蜂蜜主按鈕與底部新增入口。

## 範圍

- 四個頁面標題、閱讀三階段、書卡／摘錄／想法／自由筆記／洞察與回訪面板、書籍與立卡表單。
- 書架摘錄入口與四個捷徑移至標題下方，維持原有導向與處理。
- 閱讀路由專屬 layout、CSS 與 shell class；其他場域不套用閱讀樣式。
- 放大原有 8–12px 輔助文字與小按鈕，主要操作至少 44px 高，底部導覽居中且不超過 560px。
- 保留原有 API、資料格式、讀前／閱讀中／讀後流程、立卡、回訪與知識來源連結。

## 驗證

- `npm run build`：正式編譯與 TypeScript 通過。
- `npm run test:reading-knowledge`：來源身份、搜尋、關聯、分類與並行儲存等既有回歸測試通過。
- `UI_PRODUCTION=1 npm run test:reading-knowledge-ui`：實際瀏覽器分類衝突保留輸入、來源定位、閱讀卡片與知識庫串接通過。
- `UI_PRODUCTION=1 npm run test:reading-visual`：四個閱讀頁面在 320、375、390、430、1024px 無橫向溢出；標題配色、導覽位置、按鈕尺寸、書籍表單驗證、三階段切換、立卡視窗與回訪面板通過。另確認切換至野採紀錄頁時不保留閱讀 shell。
