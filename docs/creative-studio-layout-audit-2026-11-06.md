# 創作工作臺完整介面稽核與修復

## 範圍

以目前同檔HTML第12版與對應原生工作臺為基準，檢查兩場域、A/B/雙C/D、來源、方向、候選分欄／設定、研究清單恢復／重點／歷史、完稿與發布交接；HTML另檢查圖文／Motion製作討論、指令、試作回收與完成區。維持正式場域配色、既有版面和八種方法，不改正文或作者決策。

## 判定依據

使用UI/UX指引的觸控間距、重排、標籤、焦點和安全區規範。手機網頁以44 CSS px作本專案舒適觸控目標，與原生pt單位區分；相鄰操作至少8px，主要操作48px以上。共享既有8/12/16/24間距，不建立新視覺主題。

特定Next表單查詢沒有可直接解決間距的有效匹配；本輪不據此更換API或表單架構，採用已匹配的跨框架觸控／文字重排規則與實際渲染測量。

## 第12版實際發現

- 研究清單恢復預覽的確認／取消直接堆疊，垂直間隔0。
- 重點卡展開標題／討論按鈕、空例子／候選／研究收合標題與新增按鈕之間0間隔。
- 五步驟入口間隔4px，低於本輪採用8px舒適標準。
- A的方向歸屬、方向管理等獨立連結只有24px左右文字高度，缺少觸控空間。
- 原生工作臺對應154個狀態尺寸組合發現40個小目標、770個重複間距違例；含媒體分區後共210個組合，124個重複小目標。不是770種不同bug；同一控制項會在兩場域及多尺寸重複計數。標籤到欄位、水平溢出及未命名表單欄位當時未發現違例。
- 真實scroll/focus到文章選單、本人問題／回答、整合貼回及保存，在390×844、縮短視窗390×500、橫向844×390均未被固定工具列遮蓋。不以任意離屏內容位於導覽下方當作焦點遮擋。

## 修復

- 步驟列間距8px；保留原順序和五欄。
- 展開收合標題與後續內容間隔12px，涵蓋空／有資料兩種狀態。
- 預覽內直接操作改全寬、最小48px、上下12px；重點卡討論操作亦相同。
- 獨立方向管理連結最小44px點按範圍。
- 小手機研究卡內距調為12px，減少多層卡片壓縮寬度；研究條目／預覽條目補一致留白和分隔。
- 圖文／Motion返回連結也補44px點按高度；研究問題、回答及素材搜尋的提示字原對比約2.74，改用既有可讀的muted色。
- 聊解室媒體選中選單原有淺底＋白字樣式衝突，文字對比約1.13；修正為場域淺底＋深墨色，保留選中底線與aria-pressed狀態。
- 功能、文案內容、文章與任務快照不因介面稽核改寫。

## 驗證方式

scripts/audit-studio-layout.mjs在實際瀏覽器讀取矩形與可見控制項，而非只看CSS字串；涵蓋320/375/390/430、150%字級、橫向844×390、1024桌面。各層收合可展開、長研究名稱／出處、候選／重點／本人回答／完整回覆均用合成資料；無個人文章提交。

每個欄位用Range量標籤與控制項間距，相鄰按鈕／收合標題量實際間距，獨立連結／選項／輸入量可點尺寸；檢查水平溢出、標籤及頁面錯誤。另以實際焦點與elementFromPoint檢查底部導覽／保存遮擋。已先在原版看到間距斷言失敗，修復後再驗。

完整功能回歸使用既有資料/API及原生／HTML流程，含B回覆、研究恢復、複製貼上／失敗恢復、多輪討論、雙C、逐點整合、備份還原與媒體保留。視覺通過不推論實際GPT內容與研究正確。

最終原生154組／HTML210組均通過上述矩形、間距與標籤規則；被測文字與提示字對比通過。亮色及OS深色偏好皆維持既有淺色場域，不新增深色主題。完整功能回歸通過；詳見相鄰results JSON與delivery紀錄。仍非iPhone/Safari實機、VoiceOver或實際鍵盤遮擋驗收；OS深色模式下固定淺色場域需另檢查計算色彩，不宣稱另做深色主題。

## 本輪執行經驗

無水平溢出不能推導可用的間距、觸控面積或顏色；必須分別量測。跨場域要核對選中狀態的實際文字／底色組合，而非只看單一CSS宣告。Tailwind新版本會產生oklab/透明色，對比測試以瀏覽器實際轉色及合成，不使用僅支援rgb字串的解析器造成假警報。焦點遮擋用實際scroll/focus與命中測試；一般離屏內容不當作被導覽遮擋的錯誤。此為專案執行經驗，非新全域偏好。
