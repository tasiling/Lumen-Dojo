# 織光堂／聊解室創作系統整合

## 功能基準與不可更動項目

依本對話已確認的 Q1–Q24，使用附件 `weaving-liaojie-workflow-v1(1).html` 核對功能；沿用正式工作台保存、固定版本與可重試寫入。不是以入口或配色判定移植完成。

- 織光堂、聊解室各有開始創作、接續作品、創作工具入口，共用底層作品資料。
- 八種創作方式的名稱與設計保留；原工具過渡保留。
- AI 維持複製指令、在 ChatGPT 執行、貼回回覆；沒有新增網站自動 AI。
- AI 完整回覆、本人回答／決定、候選主文、採用稿與各輪來源設定分開保存。
- 原文和衍生稿各自列出、相互連結，狀態獨立；上游改變只提示，不自動重寫。

## 目前已實作的功能

| 範圍 | 行為與核對重點 |
| --- | --- |
| 兩場域入口 | `/weaving/works` 與 `/liaojie/works` 共用作品；圖文也有各自場域路由，保留返回入口。 |
| A | 素材／方向／草稿三起點；本人回答與完整回覆分開；多輪與多候選保存；可暫存、新方向、新題目、接入既有方向的新理解版本。 |
| B | 修改幅度、六種框架與收束設定；逐筆研究用途／來源／限制及案例採用狀態進指令；研究與案例不由 AI 自動採用。 |
| C | 轉製與擴寫各存底稿、回覆與候選主文；可明選目前稿或固定版本；轉製另建獨立稿，擴寫更新原稿並保留歷史。 |
| D | 同作品固定完成版，不要求先發布；保留原四軸與三層分析、來源引句及位置；舊格式也可預覽候選。 |
| 指令規格 | 恢復原限動金句定位、五框比較、頁數及導流細則、各框架擴寫對照與節奏雕刻；B 不強迫理論入文，A 不強迫素材探索套六段。 |
| 回覆整理 | 固定標題、原 A JSON、原 D 四軸格式可協助分欄；先預覽再確認，原文保留；無法辨識可手動處理。預覽綁定來源版本與文字，換來源後必須重新辨識。 |
| AI 檢查 | 檢查指令包含本輪設定、來源與完整回覆；檢查回覆另存輪次；採用仍由本人執行。 |
| 作品狀態 | 預設進行中，完稿與封存分開；類型／平台篩選、批次封存及恢復；完稿須開始修訂才可改正文，封存須先恢復。 |
| 備份搬遷 | 支援 prototype JSON `state` 包裝、研究物件、雙 C、本人回答、BC／Journey 輪次、候選、固定文字與圖文完成版；重複匯入接續同紀錄。 |
| 原生備份恢復 | 原件在時接續原 ID，不覆蓋較新內容；原件缺失時保留封存／完稿保護、衍生來源連結、固定版本當時意思及目前完成版對應。 |
| 素材對應 | 舊選摘以全域片段編號轉換，保留每份來源、片段／時間位置、校訂版本與另貼文字；原文保留；私人範圍保留，外部及公開許可不自動開啟。 |
| 候選重試 | 保存候選來源快照；失敗前已建立的題目可接續，無關編輯後重試也不重複建立題目或覆寫其他輸入。 |
| 舊圖文 | 預覽五種原版型、1080×1350／1920、文字位置字級、署名頁尾與配圖，再另存為可編輯圖文版本；既有版本及成品保留。圖片來源標為待核對，不冒認本人創作或 AI 生成。 |
| 圖文專用舊作品 | 沒有文章主稿也可搬遷；固定圖文以逐頁原文字錄作為文字來源錨點，原配置仍保留，沒有虛構文章或新成品。 |
| 成品交接 | 圖文 PNG 保存、可修改來源下載／載回、Canva 逐頁文字／版型交接，以及噗浪／IG／Threads 發布準備沿用固定版本。沒有宣稱自動操作 Canva 或自動社群發布。 |

## 本批查核中修正的缺陷

- 修復原全域素材選摘被誤當成單份來源索引，避免帶入未選素材或漏段。
- 恢復原生備份時維持封存／完稿、原文與衍生稿關係，以及固定版本當時的本人意思；不以目前草稿設定替換舊快照。
- 修復候選連結部分完成後，另存無關討論再重試會重複建題目的問題。
- 修復只有圖文的舊完成版無法選為搬遷來源；原 `original` 經驗案例轉為 `experience`，不誤轉成假設。
- 回覆辨識預覽綁定來源，避免換完稿後把舊引句重新標上新版本。
- 雙 C 的底稿和案例設定不互相覆蓋；固定版本的作者意思與本輪明選研究／案例同時進指令。
- 長稿採用後的完整設定快照可讀取，新增寫入前完整驗證；輪次不遞迴包入既有輪次。
- PNG 匯出略過空文字節點，避免空白頁尾被誤判為越界。長文字不截斷；真正超出圖文版面仍阻擋輸出。

## 11/04 草稿審閱補修：靈感給 A、草稿給 B

使用者以實際 HTML 截圖指出，工具入口仍進入「封閉知識煉金 v9」，缺少先前已確認的起點說明。核對後確認：原生 A/B 功能雖已存在，工具目錄及舊路由未清楚區分，舊頁還在要求先貼草稿、先做 A 結構診斷再進 B。先前自動化測試沒有驗證這項入口語意，不應以測試通過宣稱已完整承接。

- 兩場域首頁、工具目錄與舊知識鑽石頁共同提供「靈感給 A，草稿給 B」說明及可操作入口。建立時即固定本次 A 或 B，直接開啟編寫區並保留場域路由。
- A 可直接貼觀察、感受或零散素材；B 可直接貼草稿，另填本人確認意思，不以 A 回答當前置條件。可在同一作品切換，沿用本次選摘，不另建副本。
- 工作台的起點說明可展開查看，避免遮住實際編寫區；所選模組仍有明顯簡介。來源取用許可在輸入旁確認，私有來源仍受保護。
- 舊 v9 明確標為舊版草稿與備份；保留其儲存鍵、表單及指令原規則，提供匯入與新版入口。舊修改尚未保存時不直接離開。
- 離線驗證遇到瀏覽器拒絕 Clipboard API，已補選取複製備援；兩種複製皆失敗仍提示手動選取，不回報假成功。
- 本輪更新草稿 HTML 與待審程式，沒有部署正式站，也未自動搬遷或刪除舊資料。

驗證結果：production build／TypeScript、修改程式檔 ESLint 及 diff 檢查通過。既有兩組原生瀏覽器流程通過；新增四組原生入口測試通過（雙場域 B 直入、本人意思進指令、保存重開、同作品切換、A 靈感起步、舊版界線）。離線 HTML 的四組入口、十組完整流程、兩組備份回載均通過；320／390／430／1024 寬度沒有橫向溢出，沒有未處理瀏覽器錯誤或對外 HTTP 請求。剪貼簿拒絕與完全失敗的回歸測試也通過。尚非使用者手機實測或正式資料驗收。
