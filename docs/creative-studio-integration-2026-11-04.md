# 織光堂／聊解室功能整合

## 已確認的需求

依本次 Grill me Q1–Q24：以整合測試版功能為核對基準，保留正式保存／固定版本；兩場域入口共用作品及素材；AI 採複製貼上；A/B/C/D 不強迫依序完成。八種創作方法名稱與設計不改。

- A：素材／已有方向／已有草稿；本人回答、AI 回覆分開；候選不等於作者確認；多方向持續保存。
- B：修改幅度、框架、收束、逐筆研究用途及案例採用進指令；完整回覆、候選主文、編輯說明分開。
- C：轉製及擴寫各存文字；可選目前稿或固定完成版；轉製建立獨立稿、來源互連，擴寫修改原稿並保留歷史。
- D：同作品固定完稿為依據，不需先發布；原測試版四軸（垂直深挖／水平平移／反面驗證／跨系統嫁接）、三層（候選節點／跨主題連接／三分類地圖）；保留引句及位置。
- 素材原文不改，校訂追加；只選本次使用部分；私人素材不自動公開。
- 整段回覆辨識預覽、手動處理及 AI 檢查；檢查結果獨立輪次；採用才改正文。
- 進行中／完稿／封存分開，預設只列進行中。原稿及衍生稿獨立顯示、互連、各自狀態，沒有父卡收納。
- 完稿「開始修訂」才改正文；保存協作紀錄不使完稿回到進行中；發布紀錄與固定版本另存。
- 上游更新僅提示；備份先預覽、保留原始證據，重複匯入接續識別；不能把封存當已轉換。
- 圖文／Canva／三平台準備接續固定版本；外部自動生成與自動發布另列。
- 舊版最終移除，但必須新版流程、可編輯資料、還原測試及本人手機驗收通過。此批不移除。
