# 閱讀與知識整合交付

日期：2026-10-19（墨爾本）
分支：`codex/reading-knowledge-integration`。

## 功能

- 道藏新增「閱讀與知識總覽」；閱讀首頁可進入總覽、洞察卡片庫與知識庫。
- 原 `/dao/knowledge` 改為「知識庫」，保留四個管理分區、採用、成熟度、用途及版本功能。
- 總覽搜尋閱讀筆記正文及理解、閱讀洞察及行動結果、目前知識主張。可依種類、書籍讀次、主題、關聯學科篩選。沒有分類的內容仍可搜尋。
- 每筆內容保留原資料位置；原管理頁支援 `note`、`card`、`claim` 定位，失效紀錄明確提示。
- 「來源與後續」以實際引用推導直接關聯；舊資料缺筆記來源時只連到可確認的書籍，不猜測。原文與反思片段分開識別。
- 「主題與學科」可留空、多選、沿用書籍學科或關閉繼承；既有封存／不可用學科關聯不會被自動移除。
- 分類存在獨立管理註記，不改筆記正文、洞察結果、知識版本、採用狀態、作品快照或學習完成數。

## 保存與讀取

原 DB21 書籍／筆記區塊、DB22 洞察、DB14 知識與作品不搬移。新增 DB14 前綴 `行光閱讀知識分類-v1-` 排除於一般知識掃描。學科讀取既有修習底座 items，不初始化第二份學科。

所有新 API 使用既有 access-key session；寫入拒絕跨來源請求。來源歸屬、分類長度、學科存在性與 revision 由後台核對。分類操作用共用持久鎖及 `LEARNING_WRITE_LOCK_DIR/reading-knowledge-operations` 下的持久操作收據；相同識別與內容可重播，結果不明時保留鎖且不重新派送。

搜尋游標為簽名的不透明識別，綁 owner 與條件，內容不放入網址；狀態在伺服器記憶體，15 分鐘到期或重啟需重新搜尋。每次按來源分批讀取，結果 20 筆一頁。部分來源失敗或未完成會明示；同一游標重試不跳頁。原始來源更新後不保證分頁是全庫同一時刻快照，可重新整理取得新結果。

## 獨立審查修正

1. 來源暫時讀取失敗仍可續查，不消耗掉失敗項目或顯示假完成。
2. 關聯保留知識各版本的實際引用；搜尋仍只列目前主張。
3. 選書篩選會核對知識來源的真實書籍／讀次歸屬，支援多書關聯。
4. 讀前與讀後的所有已保存欄位都可搜尋，舊紀錄定位也完整顯示。
5. 單筆直接查詢並核對來源資料庫／書籍父層，不在分類寫入鎖內掃完整個書庫。
6. 分類後台暫時失敗時保留可讀取內容，分類篩選待核對項可重試且不無限累積。
7. 理解片段使用自己的分類與來源關聯，儲存不會改到原筆記註記。
8. 成品關聯連到正確作品與指定成品，展開相應版本；逐段引用版本留在快照文字中。
