# 野採雙成熟度與知識主張第一階段

## 本階段邊界

- 野採材料保存創作成熟度 C0–C3，以及來源成熟度 K0／K1；材料本身不會因整理過就成為 K2–K4 知識。
- K2–K4 屬於獨立 `KnowledgeClaim`，以固定 ID、版本、來源與人工採用狀態保存。
- 現有 DB14 JSON 儲存方式不變；Claim 使用獨立前綴 `行光知識主張-`，並排除於舊知識列掃描。
- 不接 LLM API、不建立向量資料庫、不自動把素材或閱讀洞察升格為知識。
- 「我的知識」「知識主張庫」都是暫用介面名稱；資料模型名稱不依賴日後品牌命名。

## 現有資料映射

| 現有欄位 | 第一階段處理 |
|---|---|
| `processingDepth` | 保留為整理深度，不再兼任創作成熟度 |
| `forageReason` | 沿用為「我為何在意」 |
| `sourceUrl`、`excerpt` | 保留原始來源與內容快照 |
| `knowledgeLinks` | 保留為舊式文字標籤，不假裝成穩定 Claim 關聯 |
| `destinations` | 保留去向；送織光堂時另檢查 C2/C3 |
| 新增 `creativeMaturity` | C0、C1、C2、C3 |
| 新增 `sourceKnowledgeMaturity` | K0 未處理來源、K1 可追溯來源；K2–K4 不重複存在 Capture |
| 新增 `sourceLocator` | 頁碼、段落、時間碼等可定位資訊 |
| 新增 `claimRefs` | 以 `claimId + relation` 連到正式 Claim 紀錄 |
| 新增 `llmMaterialUse` | `disabled` 或 `inspiration_only`；材料不可作事實證據 |

舊資料讀取時：raw 推定 C0，light/deep 推定 C1，來源成熟度保守視為 K0。系統不自動推定 C2、C3 或 K1，也不自動建立 Claim。

## Claim 狀態規則

- K2：候選主張，可保存但不代表採用。
- K3：已評估，可標記部分支持、仍有爭議或已反證。
- K4：Crystal 明確採用的正式版本。
- 成熟度與生命週期分開；K4 日後可以變成 `refuted` 或 `superseded`，保留為知識歷史。
- 已採用、已反證或已被取代的版本不可覆寫文字；修改必須建立新版。
- `currentVersionId` 指向正在審閱的版本，`activeVersionId` 指向目前正式採用的版本。建立新版不會讓舊 K4 提前失效；新版正式採用後才取代舊版。
- 理解知識採用前需有來源；經驗知識需有觀察紀錄；方法知識需有使用紀錄；所有 K4 都需有適用邊界。

## 已建立的人工橋接

1. 野採：K1 材料可明確建立 K2；伺服器會成套保存 Claim 與 Capture 的反向 ID，失敗時不留下孤兒 Claim。
2. 閱讀洞察：已驗證或不成立的洞察可人工建立 K2，帶入書籍、洞察 ID、行動與結果；洞察狀態不會自動等於 K4。
3. 織光杼：目前核心經線可建立立場候選；作品回杼可建立經驗候選。作品全文仍是 Artifact，不整篇視為知識。

## 英文修習邊界

- `EnglishImageEntry` 是學習素材；OCR 與 AI 分析完成不代表知識成熟。
- VocabForge 單字是記憶資產，不接入 Claim。
- 語境修習成果是實作證據；日後可以由使用者抽出方法或經驗候選，但不自動升格。
- `行光英文影像-`、`行光語境成果-`、`行光知識主張-` 使用獨立前綴並同時列入正式 JSON 排除清單。

## 後續 LLM 接口

1. 查詢帶入 `use=inspiration|perspective|evidence|style` 時，只回傳 `activeVersionId` 所指向、由 Crystal 採用且允許該用途的 K4。
2. 下一階段建立可預覽的知識脈絡包，再評估全文搜尋、語意檢索、向量索引與實際 LLM 對話。

## 合併與部署前檢查

- 以真實野採逐一驗證 C0、C1、C2、C3 的儲存與重新讀取。
- 確認只有 adopted + weaving + C2/C3 會出現在織光堂素材入口。
- 由野採建立 K2 後，確認 Claim 與 Capture 兩端 ID 關聯都可回找。
- 驗證 K2 保存、K3 部分／爭議、K4 採用、反證、新版與封存。
- 驗證 K4 舊版不可被原地覆寫；建立新版時舊版仍 active，新版採用後舊版才 superseded。
- 確認 DB14 的舊知識查詢不會把 `行光知識主張-` JSON 當成一般知識列。
- 使用 390px 以下手機實機檢查頁籤、C 軸按鈕、長主張、來源快照與操作按鈕。
- 確認未觸發週盤、今日三件事、聊解室或任何自動發布行為。
