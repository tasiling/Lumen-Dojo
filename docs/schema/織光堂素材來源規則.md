# 行光道場｜織光堂素材來源規則

2026-11-25 依〈心知閱讀與各場域接線稽核〉的裁決修正。

## 洞察卡（DB-22）

規則集中在 `lib/reading/insightUse.ts`，以下四處共用：作品的來源選擇器與選取核對（`weavingWorkflow/sources.ts`）、洞察卡頁「組成企劃」（`weavingWorkflow/store.ts`）、舊版企劃 API（`app/api/dojo/weaving-projects`）、來源設定與 GPT 提案（`creativeSources/resolver.ts`），以及工作室目錄（`weavingStudio/catalog.ts`）。

- 可用於作品：所有洞察卡，只排除狀態為「放棄」的閱讀洞察卡。
- 野採淬鍊卡沒有自己的狀態（讀取時視為「觀察中」），狀態不會擋住它。
- 標記：
  - 閱讀洞察・已驗證／閱讀洞察・不成立
  - 閱讀洞察・觀察中・尚未驗證（待行動、行動中同理）
  - 野採淬鍊・<類型>・本人原話
- 標記會出現在來源選擇器、工作室卡片，並隨選取保存在作品的來源紀錄。
- 作品取得的文字：閱讀洞察卡維持原本的「洞察／行動／結果」；野採淬鍊卡是「我的原話」加上「依據的原文」。
- 閱讀洞察卡的來源版本沿用原本的算法，已經選過的作品不會被判定為「來源已更新」；卡片之後轉為已驗證，也不會因為標記改變而失效。

## 野採採集進工作室目錄

保留三個門檻：已採用、成熟度 C2 或 C3、去向包含織光堂。原本額外要求標題含「訪談」或「訪問」的條件已移除。

- 標題含「訪談」「訪問」的仍標為「訪談重點」。
- 其他採集標為「野採採集」，連結回採集頁。

## 道藏的來源關聯

- 新增內容種類 `forage_capture`（野採採集），標題前綴 `行光捕捉-`，連結 `/forage/captures?captureId=<id>`。
- 野採淬鍊卡以 Notion「來源採集」欄位接成來源關聯；作品與知識主張選用的野採採集也會出現在該採集的「後續使用」。
- 採集頁的「探索」分頁新增「來源與後續」面板。
- 淬鍊卡在總覽與關聯中顯示「我的原話」與「依據的原文」，不再套用「行動／結果」格式。

不搬動、不改寫 Notion 裡的既有資料。規則測試：`npm run test:insight-use`。
