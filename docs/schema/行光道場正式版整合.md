# 行光道場正式版整合

## 邊界

- 個人生活流程：今天、晨間啟動、今日三件事、白天追蹤、日間札記、晚間收光、週盤、個人行程、回看。
- 內容生產流程：日上三更、Session、組稿、序列展開、生產日、快速評分、噗浪蓋樓。
- 兩套流程可在整合行事曆同時檢視，但日上三更不會成為晨間啟動、日間札記或晚間收光的內容。

## 主導覽

固定為：

1. 今天 `/`
2. 行事曆 `/calendar`
3. 新增（快速紀錄／新增行程）
4. 週盤 `/bingo`
5. 回看 `/review`

## 持久化模型

沿用專案既有「DB-14 知識庫標題前綴 + 內容 JSON」模式，不修改 Notion schema：

| 前綴 | 一筆資料的範圍 | 主要內容 |
| --- | --- | --- |
| `行光今日-YYYYMMDD` | 每日一筆 | 晨間、三件事、白天追蹤、日間札記、晚間復盤 |
| `行光週盤-YYYYMMDD` | 每週一筆（週一起算） | 25 格、完成時間、連線、今日指派、每週回望、封存 |
| `行光行程-YYYYMMDD-*` | 每個個人行程一筆 | 日期、時間、場域、類型、說明 |
| `行光紀錄-*` | 每個快速紀錄一筆 | 六場域、隱私、光行／光法、測頻、建立與更新時間 |

- 快速紀錄不再依賴 React 記憶體或 `localStorage`。
- 非私人快速紀錄繼續同步到 DB-19 生活痕跡；私人紀錄只存在受 ACCESS_KEY 保護的 DB-14，避免 DB-19 無隱私欄位造成外洩。
- DB-18 七題日記、DB-14 舊收光紀錄、DB-19 舊痕跡及所有 Session 資料均保留。
- 日期以 `Asia/Taipei` 判定，避免 Railway UTC 午夜造成日期錯位。

## 串接流程

1. 週盤格子選擇「排入今天」時，寫入當日三件事並在週盤格記錄來源。
2. 今天完成該任務時，同步格子完成狀態與完成時間，重新計算 Bingo 連線。
3. 晚間復盤寫入當日紀錄；帶回／寫下今天／暫且放下同步沿用既有收光 API。
4. 回看讀取每日紀錄、正式快速紀錄與整合前 DB-19 痕跡。
5. 行事曆同時讀取個人行程、每日三件事與原 `/api/dashboard` 生產排程；來源以不同標籤顯示。

## 相容性保護

- 未更動任何既有 data source ID 或既有 Notion 欄位名稱。
- 未更動 `proxy.ts` 的 cookie 驗證流程。
- 未刪除任何 Session、日上三更、生成、序列、生產日、回饋或噗浪 API。
- 舊 `/overview` 仍可使用，會導向新的整合行事曆。
- 所有刪除個人行程／快速紀錄的動作使用 Notion `archived: true`，保留復原可能。
