# 彈性週盤 v2 資料相容與操作規則

## 儲存位置

- 每週盤面仍使用 DB-14 的 `行光週盤-YYYYMMDD` JSON 紀錄，不新增 Notion 欄位。
- 可編輯範本庫使用單一 DB-14 紀錄 `行光週盤範本庫-v2`。
- 預設範本先由程式提供，只有使用者新增、編輯、封存、調整專案狀態或建立組合時才寫入範本庫。

## WeeklyBoard v3

- `taskInstanceId`：本週任務實例的穩定識別。移動只改 `index`，不改此 ID。
- `templateId`：可選的來源範本 ID；修改本週實例不回寫範本。
- `completion.mode`：`single`、`count`、`specified`、`free`。
- `note`：本週實例補充說明。
- `removedTaskHistory`：替換或移除時保留舊實例及進度，最多保留最近 100 筆。
- `completedLineIds`：封存時保存當週結算的連線快照。

v1/v2 資料不需批次覆寫。`normalizeWeeklyBoard` 於讀取時補上安全預設；只有使用者再次儲存未封存週盤時才升級 v3。舊任務名稱、三色、進度、完成時間及既有學習來源均保留。

## 範本庫冪等合併

`normalizeWeeklyTemplateLibrary` 以穩定 ID 合併程式預設與已保存資料：

- 缺少的新預設只新增一次。
- 已編輯或封存的同 ID 範本以已保存版本為準，不會被重新啟用。
- 使用者自建範本與組合保留。
- 舊版寫死的「跨日回訪」、固定英文盤與日上三更手動任務不再出現在新版選擇器，但歷史週盤不刪除、不改名。

## 任務操作語意

- 編輯：保留 `taskInstanceId` 與進度；縮小目標時重新計算完成狀態。
- 替換：舊實例寫入 `removedTaskHistory`，新任務產生新 ID 且進度歸零。
- 移動：交換格子位置，任務 ID、內容與進度完整保留。
- 從本週移除：盤面回到空白格；已連到每日三件事的紀錄保留並解除週盤連結。
- 封存：保存當下 `completedLineIds`，歷史連線不隨後續範本更新變動。

日期仍由 `DOJO_TIME_ZONE` 控制，預設 `Asia/Taipei`。
