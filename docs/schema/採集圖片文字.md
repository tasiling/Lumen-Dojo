# 行光道場｜採集圖片文字（AI 讀圖）

2026-11-26。用於 Threads 這類「重要內容寫在圖裡」的貼文。

## 流程

1. LINE 貼上連結，按「補截圖」，開啟 10 分鐘補圖時間。
2. 補圖時間內傳的每張圖都掛到同一筆採集（上限 20 張）。原本只收第一張就關閉，現在會保持開啟，直到時間到或按「補完了」。
3. 需要時才按「讀取圖片文字」：LINE 或網頁採集頁的「圖片文字」區塊都可以。不會自動讀。
4. AI 逐張逐字抄錄圖中文字（不翻譯、不摘要、看不清楚的字以「□」標示，並列出需要核對的地方）。
5. 在網頁逐張核對、修改，按「確認為原文」。

## 與淬鍊的關係

- 只有確認過的圖片文字會進入淬鍊原文，接在貼文或逐字稿之後，以「〔圖片文字〕」「〔圖 N〕」分段，可逐字引用。
- 原文種類標為「圖片文字，已核對」。
- 重新讀取會取代舊文字並取消確認；「取消確認」會把文字移出原文但保留內容。
- 原圖不會被更動。圖片被移除時，對應的文字一起移除。

## 資料

存在採集紀錄的 `clip.imageText`：狀態（reading／ready／failed）、逐張文字與待核對處、是否確認、讀取時間、模型與估計費用。

費用與英文影像共用 `OPENAI_ENGLISH_IMAGE_MONTHLY_BUDGET_USD` 的每月預算，達上限時不再讀取。

## 檔案

- `lib/dojo/captureImageText.ts`：讀圖指令、結果對應、併入原文的規則（純規則）。
- `lib/dojo/captureImageReader.ts`、`app/api/dojo/captures/[id]/image-text/route.ts`：讀取、儲存、確認。
- `app/components/ForageCaptureInbox.tsx`：採集頁的「圖片文字」區塊。
- 規則測試：`npm run test:capture-image-text`。
