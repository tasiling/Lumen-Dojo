# 週盤手機版 v2.5

將已確認的獨立 HTML 設計整合至原有 `/bingo`，使用原本 Notion 週盤與今日／修習成果回寫；不匯入預覽的示例任務或瀏覽器資料。

## 行為

- 八個方向、27 個常用範本；四個主要專案。Muscle Education／Magic Tree House 移出專案，舊道場／修習所專案合併至道場；舊範本與專案資訊仍封存保留。
- VF 六個面向、36 項具體候選，各項直接顯示完成條件。整份清單展開，選入前可以調整本週名稱、份量、分類及條件，不自動排入。
- 當週任務預設不另存範本；可主動另存。房間整理提供照顧自己分類與三項清單，支援逐項勾選、編輯保留相同項目進度。從今天完成整項任務時勾選全部子項目，撤銷時全部取消。
- 暫停／取消保留原任務，恢復後可繼續。續排保持 taskInstanceId、完成來源、清單和進度；來源週盤不改寫，使用獨立續排紀錄鎖定舊格進度。中斷後重試不重複新增，滿盤／封存目標拒絕續排。
- 續排來源不可整張刪除，仍可封存；已封存快照維持唯讀。人工及自動完成途徑均檢查生命週期與續排狀態；Notion 寫入邊界另保護來源快照。
- 5×5 正方形、編號與四字兩行簡稱置中。完成連線格整格金色、加粗金框，線條量測實際格中心並在文字上方穿過；橫直斜與多線都支援。盤面／清單可切換。
- 回望改用「這週值得記下的一件事」，保留原 brightSpot 儲存鍵。

## 邊界

僅新增 weekly-shell 與週盤 CSS。共用設計 token 不改；相關自動完成路徑只增加週盤生命週期保護，不重做修習所、今日、野採或語境修習室介面。

原正式週盤資料不會被新範本覆寫。使用者之前在獨立 HTML 裡輸入的示例資料不會自動遷入正式站。

## 驗證

- `npm run test:weekly`
- `npm run test:weekly-personalized`（含實際 API handler 與 Notion adapter 的隔離測試）
- `node scripts/test-r2-3-api.mjs`
- `node scripts/test-practice-events.mjs`
- TypeScript 與 `npm run build`

隔離測試涵蓋舊範本／自訂內容遷移、清單撤銷、今天完成、暫停保護、續排中斷重試、身分與成果來源保留、來源刪除拒絕、自動同步不覆寫來源。未以 iPhone Safari 或真實 Notion 使用者任務做互動驗收。
