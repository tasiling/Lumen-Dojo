## 現在可用的程式流程

- 五步文字工作頁：選材、構思、製作、確認、交接；保存後能回到原作品、段落與步驟。
- 五種模板：長文／文章、短貼文／噗浪、IG 輪播文案、IG 限動文字、口播稿。段落可增加、刪除、排序，保留畫面／聲音備註；噗浪可標示單篇或串文。
- 換模板先預覽，再另建工作版本；原稿、原核心版本、段落與備註保留。點目前模板不改稿。
- 明確的來源選摘，以及人工經驗／理解。伺服器重新核對來源、成熟度、採用版本、用途與字元範圍；不把未選全文帶入製作指令。
- 主動保存、未存離開選擇、頁籤內緩衝；延遲的保存或完成回應保留之後輸入。版本衝突可比較本機／目前保存內容，明確重新套用後再保存。
- 獨立、不可覆寫的成品版本 A／B；手動交接固定版本到聊解室。相同版本重送不另建企劃，新版本另建需明確確認。
- 聊解室保留品牌、平台、標題、封面、摘要、CTA、主題、日期、連結與回看欄位。排程只保存日期，發布需自行到外站完成。
- 回杼可沉澱、發展下一件、更新核心或建立分支；不自動採用知識、不自動完成學習或週盤。

## 啟動與整合

此交付包含相對基底的完整 Git mbox patch、修改檔案與驗證紀錄。在原 `tasiling/Lumen-Dojo` 基底或隔離分支套用 patch，安裝既有依賴後，執行上述測試與 `npm run dev`。

正式寫入需設定既有 `NOTION_TOKEN`、`ACCESS_KEY`，以及絕對路徑的 `LEARNING_WRITE_LOCK_DIR`。此目錄必須位於所有寫入實例共用的持久 POSIX 卷；不可使用正式環境的暫存目錄。沒有設定時安全拒絕寫入（503）。此功能沒有新增付費 AI 或社群服務。

公開推送、PR、合併、部署及正式資料驗收仍需另外明確授權。先保留目前私人分支。

漫畫、影片製作、圖卡排版、錄音、學科分類整合仍是後續獨立包。輪播與口播在本次交付的是文字。無自動對外發布、知識採用、學習完成或週盤完成。

真 Notion、正式卷的跨實例持久性、大型長稿實際服務 payload、iPhone Safari／原生返回與強制終止尚未驗收。頁籤緩衝是盡力保護，不承諾瀏覽器強制清除儲存後仍可恢復。程式回退時保留所有資料與成品記錄，勿刪資料補償；若需要舊程式理解新結構與版本，應先驗證相容投影，不宣稱任意版本回退都安全。

- 真 Notion 一致性與正式持久卷未驗收；隔離測試不能排除正式服務／儲存假設失敗。

- 審查後由作者以新的重現測試與整體套件驗修正，沒有第二次 reviewer；成本是測試可能仍有未涵蓋行為。
