# 織光堂／聊解室工具整合

2026-11-03 使用者以四張手機截圖要求檢查全部工具，並在織光堂、聊解室建立可進入的位置。

## 查核

- 正式站部署在 6be2d2c（PR #111）；此前介面與命名更新仍在未合併的 PR #112，不應把待發布的通過驗收誤當成正式站已更新。
- 原五工具內頁需讀取場域主題；只有外框換色不足以完成整合。
- `/plurk` 未被 creative shell 的路徑判定涵蓋，仍保留米色／墨綠舊樣式。
- 織光堂只有弱文字連結，聊解室缺少完整原工具入口。

## 本版修正

- 兩個首頁皆加入明確的「創作工具」卡片，分別進入 `/weaving/tools` 與 `/liaojie/tools`。
- 兩個工具區均列出知識鑽石、日上三更單篇、日上三更多天規劃、雜誌對話、IG 輪播與噗浪蓋樓台；另可接續文章與圖文／發布整理。
- 五個原工具在兩場域各有對應入口；外框、內頁、按鈕、選取態、提示與返回路徑沿用所在場域。織光堂粉紫，聊解室粉藍。
- 工具識別碼和 IndexedDB 保存鍵維持不變；兩條入口共享同一份草稿，不搬移或複製資料。
- `/weaving/plurk`、`/liaojie/plurk` 共用原噗浪編輯器與 API；舊 `/plurk` 保留並套用聊解室主題。草稿、範本、分樓規則及保存方式不變。
- 新路徑加入正式檔案追蹤，確保內嵌 HTML、bridge 與 CSS 一起部署。
- 八種創作方式名稱、作品內容與資料格式不變。作品畫布與輸出設定維持原有功能。
