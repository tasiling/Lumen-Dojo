# 研究多輪討論草稿

使用者確認：研究區需提供往返討論的空間。可選一至多個研究或重點、選定段落／整篇文章；本人問題、GPT完整回覆及本人的接續回答分開保存。按下一輪複製時帶入所勾選歷史與尚未送出的接續回答，保存固定任務；沒有站內AI。討論期間不強迫JSON、不自動採用或改正文。

## 修改與資料

- `ResearchWork`新增討論對象、段落、接續回答草稿、回應對象、歷史排除與結論。舊備份補預設值；舊任務仍保持原樣，新任務固定討論設定及選取輪次。
- 已保存回答為獨立`author-answer`輪，指向原GPT回覆。原輪及來源不可覆寫；未送出的回答仍由一般草稿保存與離頁保護處理。
- 整理討論後預覽已釐清／想試放／仍有疑問／暫不使用。確認後才另存結論及待決定重點；結論保留與研究採用、正文採用分開。
- 自然文字前後含說明、JSON及結尾提問可辨識。使用字串／跳脫感知的括號掃描、資料結構與來源ID驗證；多份候選拒絕猜選，掃描設工作量限制。原回覆不變。
- 文章標題與正文、缺漏來源提示；研究閱讀範圍、舊用途及八種創作方式保持既有設計。結構化原文與技術詳情預設收合。
