# 第二包：來源／閱讀知識與公開設定

本包整合 PR89 既有閱讀查找、分類、來源關聯與原處定位，另建織光堂「來源與公開設定」，不重寫閱讀正文。現階段是開發分支可審閱成果，尚未正式 merge/deploy。

## 可操作成果

- `/weaving` → 圖示入口「來源與公開設定」→ `/weaving/sources`，或在作品第一步打開素材。
- 從閱讀筆記、閱讀洞察、已採用知識、成熟野採中打開一份來源，分別設定「點點主動取材」與「來源公開方式」。預設逐次詢問／每件成品確認；閱讀筆記原文、理解片段、不同讀次各自獨立，不從整本書繼承。
- 未設定或設為只限自己查看的來源，不會進入主動提案白名單。白名單按已明確允許的識別單筆讀取並確認來源歸屬，沒有先全庫取正文再篩選；不讀取整個日記庫。這是第三包的來源基礎，尚未生成主動提案。
- 設定有修訂檢查、失敗保留、最新版本比較與明確重套；未知寫入保留同一 operationId，可在重新整理後核對原收據，不另開操作重送。瀏覽器無法保存操作識別時拒絕送出新設定。
- 定稿可以維持私人；送往聊解室前必須確認該固定成品的人物、私密細節與引用。設為不公開的選摘在伺服器鎖內阻止新交接；已成功的交接重試回原企劃。後來移除工作稿來源，不能繞過歷史成品的來源檢查。這只是內部發布準備，不會自動社群發表。
