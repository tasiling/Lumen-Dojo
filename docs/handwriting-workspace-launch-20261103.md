# 書寫修習｜首次可用版本（2026-11-03）

關聯需求：#109。此版本優先實作英文多字型的可用入口，不以英文連筆取代第一階段。

## 已實作

- 修習所首頁新增「書寫修習」入口；`/practice/handwriting` 提供四階段路線。
- 英文字型探索是獨立第一階段，可由使用者按鈕建立正式「書寫修習」學習項目、英文字型階段及每款字型主題。每款字型分別保存教材與頁碼、字型名稱、目標；沒有教材時不預建臆測的字型。
- 第二階段為連筆拆解，先理解入筆／出筆／接點；中文與左手保留後續方向。
- 連到正式既有 `/api/dojo/learning/foundation` 的 create/GET 與 `/practice/records`；記錄來源項目與 stage/topic 深連結已帶入，並在紀錄編輯器中以 owner graph 驗證，再決定預設 stage/topic。沒有新增資料庫、Notion schema 或外部服務。
- 建立學習項目、階段、字型均要求使用者明確點擊；未授權、讀取失敗、寫入不明時不自動重發 create；保留原先 revision/lock/same-origin 權限。
- 修習所頁面內原有英文、週盤、其他科目以及既有紀錄不做遷移或清理。

## 操作

1. 修習所 → 書寫修習；首次按「建立學習項目」後，按「建立英文字型階段」。
2. 每本教材辨識書體後，輸入一個字型名稱、教材與頁碼，按「建立字型主題」。
3. 從該字型卡片進入「為這款字型留下紀錄」，系統依合法 ID 預選學習項目、階段與主題；使用者填寫本次練習與發現，手動保存。
4. 管理頁可修訂名稱、教材、階段與狀態；不同字型不共用主題識別。

## 本次範圍外

- 未提供的教材內頁不能推定字形／筆順；不自動判斷字型、建立圖片範本或假定使用者已掌握。
- 尚未製作細節連筆動畫、多色逐筆拆解、描摹畫布、照片直接保存及跨次量化進度圖表。
- 此版本的練習表是引導文字；正式進度與歷史需在既有學習紀錄中保存。
- 發布前需確認 TypeScript/build、現有 learning-foundation/records API 回歸、手機 375/390/430px 與主題深連結；iPhone Safari 實機和真實資料保存應於本人驗收時核實。未執行的驗證不得列為 PASS。

## 發布風險與恢復

- 首次建立使用既有自訂學習項目 POST 而非新 seed；重複失敗時應先重新讀取確認，避免不明結果重送。
- 正式站現有主分支來源 SHA 及持久卷必須在部署前核對，僅替換至本 PR 合併 commit，其他 Railway 配置不更動。
- GitHub/程式回退不能當成 Notion 資料回退；既有正式紀錄與 ID 必須保留。
