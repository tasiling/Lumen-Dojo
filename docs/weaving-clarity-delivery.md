# 織光堂操作引導調整（2026-10-18）

## 目的與範圍

讓第一次使用的人看見開始入口，並知道正在編輯哪件作品、目前在哪一步、接下來該做什麼。依使用者確認的六項介面檢查結果調整既有流程，沿用原資料、API、固定成品版本與寫入保護。

## 已實作

- 首屏顯示開始第一件作品／繼續創作；主題清單放在入口後方。
- 保留織光杼、核心經線等名稱，增加白話說明、素材與觀點範例。
- 五步驟優先顯示；切換作品、主題設定、創作回看與封存操作可展開。
- 素材卡顯示位置與內容摘要，可搜尋已載入素材，清楚顯示選摘數量。
- 保存成功後才前往下一步；保存失敗或保存期間有新輸入時留在原步驟。
- 查看不同步驟不會產生未保存修改；完成後可直接準備發布，缺少成品時提供返回定稿的入口。
- 保存操作列固定於共用底部導覽上方；只修改織光堂的樣式規則。
- 織光堂首頁與工作區使用既有紅棕色系；聊解室維持既有藍色系。

## 驗證

- `test:weaving-clarity`：首屏入口建立實際測試作品、步驟位置、素材區分、保存失敗重試、保存後接續、成品交接、固定操作列捲動位置；320/375/390/430/1024px 無橫向溢出。
- `test:weaving-ui`：原有五模板、切換作品、離開提示、重新讀取、成品／發布保存、延遲定稿、衝突比較與套用、模板轉換回歸。
- `test:weaving`：原有領域、API、來源、寫入鎖、草稿合併、成品與審查回歸。
- TypeScript、正式建置、lint 與差異格式檢查；lint 保留一個既有 Plurk 圖片警告。
- 獨立程式審查發現固定操作列受到祖先捲動容器影響；先重現失敗，再改用織光堂專用固定定位，捲動測試通過。

瀏覽器流程使用隔離測試資料與正式處理器，未建立或改動正式 Notion 作品。iPhone Safari 實機仍待使用者實際操作回饋。
