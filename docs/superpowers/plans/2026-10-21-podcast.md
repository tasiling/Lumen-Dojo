# Podcast Implementation Plan

> Native inline；superpowers:executing-plans；最後一次fresh全包審查，非逐task派實作者。

**Goal:** 固定原稿→節目段落／本人錄音／封面→真音訊成品→聊解室。
**Spec:** docs/superpowers/specs/2026-10-21-podcast-design.md
**Stack:** Next16／React19／TS／共用媒體／SVG／FFmpeg／Playwright。

## Global Constraints
- Podcast128MiB／3600秒／音訊專用；既有short-video profile不變。
- 原始錄音不剪改；成品時間變更需本人另確認；章節按成品時間。
- 1–40段、單段稿4000字、原逐字稿40000字；封面1080方圖。
- 五步、44px、同源元件／CSS；公開許可與讀取分開；不做自動全平台／RSS上架。
- 起點遠端90b30fe／master680aca2；單一writer既有Native feature checkout，先前工作已結束。

## Review Focus
- 共用媒體profile不可放寬短片限制、跨目錄讀取或接受影片當Podcast；損毀payload與缺工具須拒絕（Task1）。
- 原音與成品不同時長、章節排序／界限、長標題封面溢出，不能生成假可用成品（Task1/3）。
- partial重試撤權、未知回應、版本切換，最後副作用不可繞過政策或產生副本（Task2）。
- JSON載入／聲音或圖片上傳中、保存中改稿、衝突後完整bundle同步，不能丟輸入或綁錯版（Task3）。
