# Comic Implementation Plan

> Native inline；REQUIRED SUB-SKILL superpowers:executing-plans，最後一次fresh全包review。

**Goal:** 固定原稿→角色／逐格分鏡與對白→真正合成短漫→聊解室。
**Architecture:** 獨立comic資料，重用owner raster資產／operation鎖／草稿及SVG匯出。
**Tech Stack:** Next16／React19／TS／SVG／Sharp／Playwright／imagegen。
**Spec:** docs/superpowers/specs/2026-10-21-comic-design.md

## Global Constraints
- 1–12格／4格一頁／1–3頁，1080×1350，左至右上至下；角色0–8。
- 角色名80／描述2000；格scene2000／speaker40／dialogue160，版面溢出拒絕。
- 圖片8MiB，來源及公開確認分開；不改原始文字／歷史版本，不自動全部形式或平台。
- 已確認格必須先解除確認才可修改；角色變更不得偷偷影響確認格。
- 同源React／CSS五步、44px、五尺寸；正式資料／merge／deploy本包不動。

## Review Focus
- 確認格可藉刪除角色、JSON重匯或換ID繞過，應拒絕（Task1/2）。
- 部分output／handoff之後撤權，不能新增引用或重複成品（Task2）。
- 換格／讀圖延遲、按鈕連按與匯入失敗不能綁錯圖或丟未存文字（Task3）。
- CJK／寬英文／換行與字體差異不得截斷對白；同源PNG順序要一致（Task1/3）。
- 衝突完整bundle／固定來源與歷史成品要保持一致，unknown不能解未明鎖（Task2/3）。
