# 織光堂與聊解室：既有流程介面對齊規格

## 意圖與授權

Crystal 於 2026-10-20 確認兩張參考圖的視覺與圖示流程方向，並要求自行安排、持續建置，先交付排程。本包把已存在的文字創作與成品交接整理成可理解、可操作的手機介面。新媒體製作與點點主動提案分階段建置，不把尚未實作的能力畫成可用功能。

本包沿用已確認設計並直接準備實作，不再次詢問例行設計或執行方式。採 Native，由主要實作者接續；需要審查時依適用技能執行。公開發布、購買服務及正式部署不是本包建置授權的一部分；完成可審閱版本後集中處理正式發布。

## 視覺契約

1. 織光堂使用已部署的粉、紫、藍漸層與交織線條；聊解室使用淺藍、紫漸層與交談圓弧。線條以可維護 SVG/CSS 製作，不把整張參考圖當背景。
2. 行動版採單欄；保留底部今天、行事曆、新增、週盤、回看五個入口。改動只限定 weaving 與 liaojie 路由；共用頁面不受影響。
3. 線性 SVG 圖示帶文字標籤，互動目標至少 44px；不以文字符號或表情替代功能圖示。選材為文件、觀點為羅盤、製作為筆、預覽為眼睛、發布準備為交接箭頭。
4. 五步固定名稱：選素材、定觀點、製作內容、預覽定稿、準備發布。首頁與工作區使用同一份步驟定義。當前步驟、可回訪步驟及完成資訊分開呈現；不得因開啟頁籤就標記完成。
5. 字體採可用繁體中文無襯線主體與一致字級。頁面大標題、卡片標題與正文有清楚層級；正文 16px、行高至少 1.5。主要按鈕文字對比至少 4.5:1，若參考圖白字粉底不達標，預覽與實作同步採深色文字並記錄差異。
6. 卡片、欄位與操作列間距一致；表單錯誤靠近欄位，載入、空白、錯誤與已有作品各有真實畫面。不能以空狀態參考圖覆蓋真實資料。

## 流程與行為

- 首頁保留開始／繼續作品、創作主題、可製作素材、工作後台入口、紀錄與計時。
- 新作品先選來源，再到觀點步驟輸入核心觀點；按既有 API 建立前仍驗證觀點。前兩步只保存可恢復的本機建立草稿，畫面明示尚未建立，不能寫入假觀點或偽造後端作品。成功建立後清除對應本機草稿，失敗保留輸入；既有未知結果恢復規則不變。
- 已存在作品沿用原來源選摘、文字模板、保存、防重、版本衝突及離開提示。改名或圖示不改寫歷史內容。
- 文字製作維持文章、短貼文／噗浪串文、IG 輪播文案、限動文字、口播稿。預覽顯示實際交付物，文案不能標記為完成圖卡，口播稿不能標記為已錄音。
- 外部 AI 入口明示帶出的已選素材、回貼候選、預覽與套用；工具成果可連回作品，避免為相同內容另建失聯紀錄。
- 準備發布仍為選定固定成品版本並手動送往聊解室。禁止把此動作寫成已發布到外站。
- 聊解室依接收成品、平台編排、預覽、發布紀錄呈現既有欄位；增加 Threads 平台值並保留舊值，不以其他平台冒充。安排日期是紀錄，非外站自動發布。

## 預覽與驗收

預覽與待上線功能使用相同 React 元件、圖示、字體與 CSS；測試注入隔離資料，不另做一套與程式脫節的示意圖。以 375、390、430px 驗收視覺，320px 檢查可用性，1024px 檢查擴充。覆蓋空白、已有作品、未保存、保存失敗、版本衝突、定稿與交接。相同尺寸與資料狀態比對；截圖來自實際渲染，字體載入完成後才擷取。全部按鈕對應實際動作，保留原有織光流程回歸。不得把隔離測試當成正式 Notion 寫入或 iPhone 真機驗收。

## 新能力邊界

點點主動提案、素材公開許可、圖片製作、短影音、Podcast、短漫及長影片，各有後續獨立工作包。未完成前保留在路線圖，不在正式操作介面提供假入口。讀者定位、外部搜尋範圍、工具付費與創作頻率尚未決定：先做設定與測試資料，不替使用者虛構偏好。
