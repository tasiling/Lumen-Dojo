# 第五包：圖文實際製作

## 目的與裁定

把本人固定的文字原稿做成可逐頁編輯、配圖、排版、輸出與交接的圖文。沿用已授權 Native 持續建置，例行設計與工具試用不再等待重複同意。本包屬新子系統，先寫規格與計畫後實作。

採獨立圖文稿件而不修改原文或把所有作品自動轉圖。入口放在織光堂及文字固定成品；選擇固定版本後建立一份圖文稿。最多 12 頁，4:5、1080×1350；可新增、移除、排序、調整標題／正文／圖像位置、文案為主或上圖下文兩種排版。長文不截斷；超出一頁時需拆頁。

## 資料與權限

- Notion 獨立系統前綴保存 deck 索引、不可覆寫 version、固定 output；每次保存新版本，沿用操作收據、共用鎖與 expectedRevision。
- 圖片保存在 `LEARNING_WRITE_LOCK_DIR/illustrated-assets` 的持久檔案中，以內容 SHA256 命名，與 owner API 同源讀取。沒有持久目錄即拒絕；不落到臨時目錄冒充長期保存。
- 僅接受實際 PNG／JPEG／WebP 點陣圖片，單張最多 8MiB，尺寸最高 8192，每張保留來源類型、工具、提示／來源註記、是否允許公開。預設未確認公開，不向外部模型自動送私人內容。
- 私人編輯可用圖；定稿、匯出與交接需重新核對文字固定來源的公開許可、每張圖的公開確認及目前版本。讀取許可與公開許可分開。
- 操作未知回應依原 operation 與遠端 marker 恢復；同一固定原稿的並行建立不重複。

## 同源預覽與輸出

產品和預覽共用 React SVG 圖卡；PNG 由同一個已渲染 SVG 轉 canvas，避免另一套排版。標題／正文有明確行數界線，溢出時停止匯出，不縮成不可讀的小字。圖使用 contain／cover 可選並保留裁切位置；預設 contain 不裁掉主體。文字與圖各自獨立，可只換圖而保留其他頁面。

匯出每頁 PNG，並提供包含頁序、文字、版型與內嵌原圖的可修改 JSON。實際輸出回存為 output，必須每頁對應目前 version 和固定來源後才可交接聊解室。聊解企劃增加圖文 outputRefs，保留既有文字版本與所有舊欄位；圖文不是另一份文字自動轉製。

## 介面與美術

沿用粉紫藍流程與聊解藍：ink #253c5c、blue #45638f、paper #fffdf8、pink #e494bf、line #d6e3f2、sage #dce9df。手機單欄、44px 操作、五步圖示。編輯器以頁序條與一張大圖卡為核心，不做密集後台表格。正文使用可用繁體中文無襯線，圖卡文字左對齊、60px 標題與36px 正文，保留安全邊界。

對 generic 模板的自查：辨識點放在「一份生活原稿長成一疊可抽換的圖卡」，配色沿用使用者確認方向，圖片可水彩／蠟筆而介面不擅自更換風格。

## 驗收與邊界

用虛構隔離題材做三頁真正 PNG。內建 imagegen 實際生成無字水彩／蠟筆配圖，回收原圖、prompt、輸出與 JSON；不購買服務或啟用新計費。手機375/390/430、320可用、1024擴充；空白／非空／dirty／失敗／衝突／定稿／交接。domain、API、UI與build、tsc、lint；一次獨立審查及集中修正。正式資料、部署磁碟、iPhone 真機另待驗收。

未支援的任意自由畫布、AI站內自動生圖、圖片內文字修改、社群自動發布明確不算已完成；仍提供真正圖片匯出與外部工具生成／回收路徑。
