# 聊解室原工具接入

Crystal 已要求直接建置五份實測好用的原工具。原方法、規則、版型和操作是本包驗收依據；不以現有兩款圖文版型或泛用段落編輯器取代。

## 交付

- 聊解室與發布工作台提供工具總覽，五個工具各自可直接進入。
- 知識鑽石框架：原 v9 final13、知識鑽石2.0五段／閉合規則、A/B/C/D模組、候選節點解析／選取。
- 日上三更指令、批次出題 v1.4、雜誌對話 v0.3、IG輪播 v1：保留全部原腳本與模板，包含原專案與PNG/TXT輸出。
- 原始附件逐位元保存於非 public 目錄，記錄SHA。原工具在不允許 same-origin 的 sandbox 執行；不得取得主站cookies、DOM、Notion或網路API。
- React外殼提供本裝置自動保存與通用JSON備份／還原。opaque sandbox 的localStorage由記憶體適配器提供，父層IndexedDB保存快照。原生專案下載仍保留。清楚標示裝置保存非雲端同步。
- 同工具多視窗保存使用版本檢查，衝突不覆蓋；保存失敗保留目前內容並可下載備份。匯入需確認，檔案類型／工具／版本不對不可套用。
- 手機320/375/390/430與桌機1024實際渲染，PNG仍為1080×1350；只補響應式容器，不改原畫布比例。
