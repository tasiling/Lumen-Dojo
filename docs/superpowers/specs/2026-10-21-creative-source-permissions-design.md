# 創作來源、閱讀整合與公開設定

Crystal 已授權持續建置；本包依 roadmap 第二包，沿用 PR89，不重做閱讀功能。版本整合只進開發分支，尚不代表 PR89 或本包已正式上線。

## 行為與界線

1. 整合最新 master 680aca2 與 PR89 head 6bdd699，保留雙親；package.json 取測試集合，隔離伺服器保留 production dotenv 防護、production 選項及字型注入。閱讀／洞察／知識各自的原紀錄、深連結、分類、歷史與成熟度規則不變。
2. 每份可用創作來源有獨立設定：`discovery`（點點主動取材）及 `publication`（來源可公開）。值為 allow / ask / private，預設均 ask；不從成熟度、分類、書籍、同主題、讀取或歷史作品推導另一項許可。不掃描個人日記或新增資料範圍。
3. 人工素材選取是本人操作，仍可自行查看及製作私人草稿。設定不把現有 owner 搜尋誤稱為點點自動取材。提供僅讀取已明確 allow 的來源白名單介面供第三包使用：先讀政策的識別，再單筆解析白名單來源，絕不先全庫取正文後篩選。未成熟／不可用來源繼續排除。
4. 設定使用獨立 JSON 紀錄前綴，不改來源正文與閱讀分類。驗證完整來源識別（閱讀 note 的 book:block[:reflection] 各自獨立）、既有來源歸屬、嚴格欄位、修訂及 durable operation 收據。無持久寫入鎖時拒絕；未知回應不得換識別重送。重複／損毀政策 fail closed。
5. 織光堂新增「來源與公開設定」入口，沿用實際 SourcePicker / 圖示 / CSS。打開一份來源才顯示雙欄設定與原處連結。未保存、失敗、衝突保留輸入，明確重新讀取並比較；關閉或換來源須處理未存設定，避免靜默丟失。設定不包含來源正文的額外副本。
6. 定稿可維持私人，不因公開設定阻止保存定稿。手動送往聊解室前，必須本人確認固定成品的人物／私密細節／引用；任何選摘的 publication=private 則拒絕交接，ask 可針對本次成品明確確認。每次送出在伺服器鎖內重查政策，以固定 completion 來源為準，不採工作稿替代。已成功交接的重試仍回原企劃，不再寫入；歷史成品不改寫。人工來源／無來源舊稿仍需本次確認。不自動社群發表。
