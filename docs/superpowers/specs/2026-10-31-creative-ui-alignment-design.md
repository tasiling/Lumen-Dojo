# 織光堂／聊解室視覺對齊

使用者要求直接優化兩場域正式介面，沿用 Native 執行與既定視覺；不重做資料流程。工作起點 PR107 `7e64cc9`，最新 master `70db289` 尚未包含 PR107。正式 Railway 讀取回覆需重新驗證，本輪不冒稱已檢查線上 DOM。

## 根因與選擇

舊 dojo、creative-interface、各工具與 studio 的選擇器重複定義：桌面仍限制 500px、欄位與勾選共用錯誤尺寸、原生工作區硬編粉色但服務端應為藍色、部分圖文工具硬編藍色、舊階段白底、巢狀卡片與間距混雜。選擇修正既有共用層與原生元件，不加新 UI 套件、不換風格、不另外畫示意頁。

使用 UI/UX Pro Max 的觸控／焦點／表單、frontend-design 的層級與一致性；Awesome 的 Friendly 參考保留柔和色彩，Bento 僅借用 4/8/12/16/24/32 間距，不套用其字型或橘色。遊戲及 Figma 專用技能不適用此工作台。

## 確認的視覺規則

- 織光堂粉紫、聊解室粉藍，深藍文字 `#253c5c`，次要文字 `#58677c`、白色表面。織光強調 `#8b3f68`，聊解 `#45638f`，沿用原漸層與 SVG 線條。
- 繁中沿用 Noto Sans TC／系統中文字型，正文與欄位 16px、行高 1.65；頁標題 26–36px、卡片標題 20–24px。小字不少於 12px。
- 手機單欄，左右 16/20px、卡內 20/24px；桌面外殼延伸至 1080px，長文控制閱讀寬度。卡片、表單、工具列共用節奏。
- 單頁主要行動清楚；首頁用 SVG 圖示＋簡短用途呈現入口；五步階段只用紅線及文字狀態，沒有白色選取塊。
- 所有控制有 44px 點選範圍；checkbox 本身 22px 配可點選標籤，不套 44px 高文字欄位規則。手機欄位不低於 16px，長文字、時間與原生選單不溢出。
- 固定導覽與保存列留安全距離，低高度／鍵盤情境保存列回到一般文件流，焦點可見；保留原有未保存、衝突與版本機制。

## 驗收

實際產品 React／CSS 渲染空白及非空、來源、B/D、定稿交接、圖文控制、服務及發布表單；320/375/390/430/1024、橫向低高度、200%字體、減少動態。檢查色彩／字型、卡片邊線、對齊、點選尺寸、長標題換行、表單超界、最末欄位與操作列。截圖逐項檢查而非只看無橫溢。雲端同源預覽另走實際互動；真機、部署與正式資料保持獨立驗收。
