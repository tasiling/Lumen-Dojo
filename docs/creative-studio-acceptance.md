# 織光堂／聊解室第一輪原生整合驗收

2026-10-30。基底 master `70db289d8d4499a6c91a7b4a3d4e395eed4d06e1`。本文件將已驗證行為與未完成串接分開；不代表正式環境已部署。

## 本輪可操作範圍

- `/weaving` 與 `/liaojie` 分開入口；原生 React／CSS 與預覽同源。既有原工具、野採、閱讀、提案與六形式媒體入口保留。
- `/weaving/works` 固定五筆分頁、名稱／ID 搜尋。作品可未歸杼；A/B/C/D、研究與正文獨立保存，校訂追加而不改原稿。
- `/weaving/topics` 保存多方向與理解版本；作品採用固定快照；已驗證 14 個方向。
- 本件定稿從既有 CompletionVersion 契約保存；D 明選同作品版本。外部 AI 許可依固定版本檢查，逐次確認只適用所選版本。
- 圖文沿用原 Deck／Version／Output／Asset 契約，加入標題與正文獨立座標、寬度、字級、行距、對齊、1080×1920 限動。超界／重疊擋輸出；舊版未調整前保留原排版。
- Canva 固定最小逐頁文字、排版與來源版本，另確認外部使用；成品連結接回指定交接。不宣稱自動套版／自動驗證成品。
- 固定文字交給既有聊解企劃、三平台稿與發布回看；原稿新版不回寫舊發布文字。
- `/weaving/voice` 取樣只來自實際發表的固定文字；本人確認偏好後可供協作指令參考。
- `/liaojie/services` 是本人管理端：人工登記、名額、集體訊息／每人解讀、私人文字下載。活動需求開啟同一原生作品，不帶入個人問題或解讀。
- 報名截止、本人儀式／製作與交付三節點，各自連行事曆。改期更新同一事件及月份索引，取消在原事件上保留取消狀態。墨爾本／台北時間明列。

## 遷移及相容

- HTML 備份先預覽，完整舊資料保留；杼、方向、理解與純文字完稿映射到原生紀錄。依完整內容身分判斷重複，不按標題或舊 ID 刪稿。
- 原生文字備份支援重新匯入：原 ID 存在時接續原件；原件缺失時恢復到可追溯的新 ID，保留原來源識別／版本／種類。
- 首次保存舊正式作品保留 canonical sourceSelections，不能將多來源壓成一個人工經驗而繞過來源公開設定。
- 原工具備份可辨識並保留，仍由原工具載入。舊非文字成品與原附件不冒充已轉成新成品。
- 舊 `/weaving/[shuttle]?work=...` 與 `/liaojie/tools/[tool]` 保留。巢狀頁的計時場域與聊解返回 fallback 已對齊。
